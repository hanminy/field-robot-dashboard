Real-Time Excavation Trajectory Modulation for Slip and Rollover Prevention

한줄 요약

경사면에서 자율 굴삭기의 슬립(slip)과 전복(rollover)을 실시간으로 방지하기 위해, 경사면 접선/법선 힘 비율 $\mu$와 영모멘트점(ZMP) $\xi$를 단일 선형 부등식으로 통합하고, Transformer 기반 굴착력 차분 예측 모델과 Robust Optimization을 결합한 QP 기반 궤적 변조 프레임워크를 제안한다.

1. 연구 배경 및 동기

1.1 문제 정의

  • 산업용 굴삭기는 건설, 농업, 광업, 임업 등에서 핵심 중장비이며, 자동화 추세가 가속화
  • 경사면 굴착(excavation on a slope)은 슬립과 전복 위험이 증가하여 더욱 도전적
  • 기존 연구의 한계:
  • 평지 굴착에 초점 [5][6][7][8] → 슬립/전복 위험 미고려
  • ZMP/마찰력 기반 안정성 연구 [10]-[16] → 굴착력(manipulation force)을 무시하거나 연속시간 토크 제어를 가정
  • 산업용 굴삭기는 유압 구동(MCV) 기반으로 저수준 디지털 운동학적 제어(low-level digital kinematic control)만 가능 → 연속시간 토크 제어 불가

1.2 핵심 도전 과제

도전 과제 설명
유압 구동 한계 MCV 기반 actuator는 포화, 히스테리시스, 데드존 등 복잡한 비선형 현상 → 토크 레벨 제어 불가
인과성 문제 (Causality-like issue) 현재 시점 $t_k$에서 다음 시점 $t_{k+1}$의 변조 $u_{k+1}$을 계산해야 하나, $f_{b_{k+1}}$은 알 수 없음
토양 역학 복잡성 기존 토양 모델은 파라미터 추정 및 계산량 문제로 실시간 적용 불가 [19][20][21]

1.3 기여 (Contribution)

  1. $\mu$와 $\xi$의 공통 분모 분수 구조를 활용하여 슬립/전복 방지 조건을 단일 선형 부등식으로 통합
  2. Transformer 기반 굴착력 차분 예측 모델 ($\Delta\hat{f}_{b_k}$) 개발
  3. Box uncertainty 기반 Robust Optimization (RO)으로 예측 오차 보상
  4. QP 형태의 실시간 최적화 → 스케일다운 굴삭기로 실험 검증

3. 방법론

3.1 DMP 기반 공칭 궤적 (Nominal Trajectory)

DMP(Dynamic Movement Primitive) 기반 2차 미분방정식으로 정의:

$$\ddot{q}_b + D\dot{q}_b + K(q_b - q_g) = f_m(s) + u \tag{1}$$

  • $q_g$: DMP 목표점 (차체 좌표계 ${B}$ 기준 상수)
  • $D, K$: 대각 상수 게인 행렬
  • $f_m(s)$: 전문가 궤적을 모방하는 shaping force [5]
  • $u$: 본 연구에서 설계하는 변조 입력

역기구학(inverse kinematics)으로 $q_b$에서 각 링크 좌표 $q_i$로의 사상이 유일하게 존재하며, 이를 미분하면:

$$\ddot{q}_i = J_i(q_b)u + n_i(q_b, \dot{q}_b) \tag{2}$$

  • $J_i(q_b) \in \mathbb{R}^{3 \times 3}$: 야코비안 행렬
  • $n_i(q_b, \dot{q}_b)$: 잔여 비선형 항

3.2 슬립 지표: 경사면 접선/법선 힘 비율 $\mu$

D'Alembert 원리로 각 축 반력을 계산:

$$f_{o\star} = \sum_i m_i(\ddot{\star}i - g\star) - f_{b\star}, \quad \star \in {x, y} \tag{3}$$

슬립 지표 $\mu$는:

$$\mu = \frac{\sum_i m_i(\ddot{x}i - g_x) - f{bx}}{\sum_i m_i(\ddot{y}i - g_y) - f{by}} \tag{4}$$

슬립 방지 조건:

$$|\mu| < \bar{\mu} < \mu_s \tag{5}$$

  • $\mu_s$: 정마찰계수
  • $\bar{\mu}$: 안전 마진을 둔 한계값

3.3 전복 지표: ZMP $\xi$

D'Alembert 원리로 ZMP를 유도:

$$\xi = \frac{\sum_i G_i \ddot{q}i + \sum_i m_i(y_i g_x - x_i g_y) + y_b f{bx} - x_b f_{by}}{\sum_i m_i(\ddot{y}i - g_y) - f{by}} \tag{6}$$

  • $G_i = (-m_i y_i, \ m_i x_i, \ I_i) \in \mathbb{R}^3$

전복 방지 조건:

$$|\xi| < \bar{\xi} < \xi_s \tag{7}$$

  • $\xi_s$: 하부 프레임 파라미터로 정의되는 안정 영역 크기
  • $\bar{\xi}$: 안전 마진을 둔 한계값

3.4 $\mu$와 $\xi$의 공통 분수 구조

핵심 관찰: $\mu$ (식 4)와 $\xi$ (식 6) 모두 동일한 분모 $\sum_i m_i(\ddot{y}i - g_y) - f{by}$를 공유하며, 분자는 가속도 $\ddot{q}_i$에 대해 선형이다.

경사각 $\psi_0 \in [-\frac{\pi}{2}, \frac{\pi}{2}]$에서 $g_y < 0$이고, 링크 중력이 지배적이므로 분모를 양(positive)으로 가정:

$$\sum_i m_i(\ddot{y}i - g_y) - f{by} > 0 \tag{8}$$

3.5 선형 부등식 제약 조건

$\mu$와 $\xi$를 변조 입력 $u$의 함수로 다시 표현:

$$\mu = \frac{A_\mu u + b_\mu - f_{bx}}{Cu + d - f_{by}}, \quad \xi = \frac{A_\xi u + b_\xi + y_b f_{bx} - x_b f_{by}}{Cu + d - f_{by}} \tag{9}$$

여기서: - $A_\mu = \sum_i m_i e_x \cdot J_i$, $\quad b_\mu = \sum_i m_i(e_x \cdot n_i - g_x)$ - $A_\xi = \sum_i G_i J_i$, $\quad b_\xi = \sum_i G_i n_i + \sum_i m_i(y_i g_x - x_i g_y)$ - $C = \sum_i m_i e_y \cdot J_i$, $\quad d = \sum_i m_i(e_y \cdot n_i - g_y)$

분모가 양이므로 슬립 및 전복 방지 조건 (5), (7)을 결합하여 단일 선형 부등식:

$$A(q_b)u + b(q_b, \dot{q}_b) + L(q_b)f_b \leq 0 \tag{11}$$

  • $A(q_b) \in \mathbb{R}^{4 \times 3}$, $b(q_b, \dot{q}_b) \in \mathbb{R}^4$, $L(q_b) \in \mathbb{R}^{4 \times 2}$

3.6 디지털 제어에서의 인과성 문제

저수준 디지털 운동학적 제어 채택으로 인해, 현재 시점 $t_k$에서 다음 시점 $t_{k+1}$의 부등식을 만족시켜야 함:

$$A(q_{b_{k+1}})u_{k+1} + b(q_{b_{k+1}}, \dot{q}{b{k+1}}) + L(q_{b_{k+1}})f_{b_{k+1}} \leq 0 \tag{12}$$

  • $q_{b_{k+1}}$, $\dot{q}{b{k+1}}$: Explicit Euler 적분으로 예측 가능

$$q_{b_{k+1}} = q_{b_k} + \dot{q}{b_k}\Delta t_k, \quad \dot{q}{b_{k+1}} = \dot{q}{b_k} + \ddot{q}{b_k}\Delta t_k \tag{13}$$

  • $f_{b_{k+1}}$: 토양 역학이 복잡하여 직접 예측 불가 → 데이터 기반 힘 차분 예측 필요

4.4 예측 오차와 Box Uncertainty

굴착력 예측은 오차 $\Delta e$를 포함:

$$f_{b_{k+1}} = f_{b_k} + \Delta\hat{f}_{b_k} + \Delta e \tag{14}$$

여기서 $\Delta e := \Delta f_{b_k} - \Delta\hat{f}_{b_k} \in \mathbb{R}^2$이며, box uncertainty로 모델링:

$${\Delta e \in \mathbb{R}^2 : |\Delta e_\star| \leq \zeta_\star, \quad \star \in {x, y}}$$

실험에서 $(\zeta_x, \zeta_y) = 0.05$[N]으로 설정.

5. Robust Optimization 기반 실시간 궤적 변조

5.1 불확실 선형 부등식

예측된 굴착력 (14)를 슬립/전복 조건 (12)에 대입:

$$A_{k+1}u_{k+1} + b_{k+1} + L_{k+1}(f_{b_k} + \Delta\hat{f}_{b_k} + \Delta e) \leq 0 \tag{15}$$

5.2 RO(Robust Optimization) 적용

$L_{k+1}\Delta e$를 행 벡터 $l_{k+1}^j \cdot \Delta e$로 분리하면, worst-case 상한:

$$l_{k+1}^j \cdot \Delta e \leq |l_{k+1}^j \cdot (\zeta_x, \zeta_y)|_1$$

따라서 (15)는 다음으로 변환:

$$A_{k+1}u_{k+1} + b_{k+1} + L_{k+1}(f_{b_k} + \Delta\hat{f}{b_k}) + N{k+1} \leq 0$$

  • $N_{k+1} \in \mathbb{R}^4$: $l_1$-norm 벡터 스택

5.3 QP 정식화

최종 최적화 문제:

$$\min_{u_{k+1}} \lambda_u |u_{k+1}|^2 + \lambda_h |u_{k+1} - u_k|^2 \tag{16}$$

$$\text{s.t.} \quad \underline{u}{k+1} \leq u{k+1} \leq \bar{u}_{k+1} \tag{17}$$

$$A_{k+1}u_{k+1} + b_{k+1} + L_{k+1}(f_{b_k} + \Delta\hat{f}{b_k}) + N{k+1} \leq 0 \tag{18}$$

비용 항 의미
$\lambda_u |u_{k+1}|^2$ 변조 크기 최소화
$\lambda_h |u_{k+1} - u_k|^2$ 변조 변화 smoothing (계층적 비용)
(17) 유압 구동 한계 (관절 속도/가속도 제한)
(18) 슬립/전복 방지 제약 (RO 포함)

이를 표준 QP 형태로 변환:

$$\min_{u_{k+1}} u_{k+1}^T P u_{k+1} + q \, u_{k+1} \quad \text{s.t.} \quad G u_{k+1} \leq h \tag{19}$$

→ 오픈소스 솔버(예: SciPy [24])로 실시간 해를 구함.

  • 실험 경사: $\psi_0 \in {30°, 35°}$ (양의 경사면)
