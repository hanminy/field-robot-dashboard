Precision Motion Control of Robotized Industrial Hydraulic Excavators via Data-Driven Model Inversion

한줄 요약

산업용 38톤급 유압 굴착기(Doosan DX380LC)의 입력 지연(input delay)과 사장대(dead-zone)를 물리 기반 모듈형 데이터 구동 모델로 학습하고, 그 역변환(model inversion)을 이용한 피드포워드 제어 + P 제어 프레임워크로 굴삭/정지 작업에서 경로 추종 RMSE 2 cm 이하의 정밀 제어를 달성한 연구이다.

1. 연구 배경

1.1 문제 정의

  • 유압 굴착기는 높은 출력 대비 무게 비율로 건설/광업 등에 필수적이나, 다관절 동시 조작이 필요하여 숙련 조종사에 의존
  • 자동화의 핵심은 정밀 모션 제어이지만, 산업용 유압 시스템의 고유 특성으로 인해 여전히 난제:
  • 입력 지연(Input Delay): MCV(Main Control Valve)를 통한 복잡한 유압 회로에서 발생
  • 상태 의존 사장대(State-dependent Dead-zone): 조이스틱 입력과 실린더 속도 간 비선형 관계
  • 토양 상호작용(Soil Interaction): 굴삭 시 큰 외력이 동적으로 변화

1.2 기존 연구의 한계

접근법 대표 연구 한계점
모델 기반 제어 [3]-[6] 유압 시스템의 단순화 모델링 → 제어 성능 저하
RL 기반 (단일 MLP) Egli & Hutter [7],[8] 파라미터 57,476개, 학습 10시간, 느린 속도(10-20 cm/s)에서만 검증
RNN 온라인 학습 Park et al. [9],[10] 굴삭 시 RMSE > 1 m의 큰 추적 오차
단일 액추에이터 힘 제어 Kim et al. [11] 대차원 히스토리 입력, dead-zone 미고려
Dead-zone 보상 [12],[13] 상태 의존성을 표현하지 못함

1.3 본 논문의 기여

  1. 물리 기반 모듈형 데이터 구동 모델: IIR unit + PL map + MLP로 입력 지연, dead-zone, 비선형 동역학을 분리 학습
  2. 모듈형 역변환 제어: 각 모듈을 독립적으로 역변환하여 학습 속도 대폭 향상
  3. 안정성/강건성 이론 보장: Proposition 1, Theorem 1으로 수학적 증명
  4. 실기 검증: 38톤급 상용 굴착기에서 토양 상호작용 하 RMSE < 2 cm 달성

3. 핵심 기술: 데이터 기반 모델 역변환 (Data-Driven Model Inversion)

700 Fig. 3. 데이터 기반 모델 역변환 프레임워크 및 오프라인 학습 스키마. 오른쪽: Excavator Plant Model (순방향), 왼쪽: Inversion Control (역방향). 각각 PL map, IIR unit, MLP 모듈로 구성.

3.1 Excavator Plant Model (순방향 모델)

조이스틱 신호 $u_t$로부터 관절 각속도 $\hat{\omega}_t$를 예측하는 3단계 모듈형 모델:

$$\eta_{f,t} = f_{\Gamma_t}(u_t) \tag{1}$$

$$\mathcal{Z}{\eta_{h,t}} = P(z)\,\mathcal{Z}{\eta_{f,t}} \tag{2}$$

$$\hat{\omega}t = h{\Gamma_t}(\eta_{h,t}) \tag{3}$$

여기서: - $f_{\Gamma_t}: [-1,1]^3 \to \mathbb{R}^{n_f}$ — Pre-delay map (PL map): 상태 의존 dead-zone 포착 - $P(z)$ — Delaying system (IIR unit): $n_h \times n_f$ LTI 전달함수 행렬, 다중 입력 지연 모델링 - $h_{\Gamma_t}: \mathbb{R}^{n_h} \to \mathbb{R}^3$ — Post-delay map (MLP): 잔여 비선형 동역학 및 커플링 - $\Gamma_t := (\theta_t, P_t^{\text{cyl}}, P_t^{\text{pump}}, F_t^{\text{ext}}) \in \mathbb{R}^{13}$ — 굴착기 상태 벡터

굴착기 상태 벡터 $\Gamma_t$의 구성:

변수 차원 설명
$\theta_t = (\theta_t^{\text{boom}}, \theta_t^{\text{arm}}, \theta_t^{\text{bucket}})$ $\mathbb{R}^3$ 관절 각도
$P_t^{\text{cyl}}$ $\mathbb{R}^6$ 실린더 헤드/로드 챔버 압력
$P_t^{\text{pump}}$ $\mathbb{R}^2$ 펌프 2개의 압력
$F_t^{\text{ext}}$ $\mathbb{R}^2$ 버킷 끝단 수평/수직 외력 (토양 상호작용)

3.2 Excavator Plant Model Inversion Control (역변환 제어)

명령 관절 각속도 $\omega_t^{\text{cmd}}$로부터 조이스틱 신호 $u_t$를 계산하는 역방향 3단계:

$$\zeta_{h,t} = g_{h,\Gamma_t}(\omega_t^{\text{cmd}}) \tag{4}$$

$$\mathcal{Z}{\zeta_{f,t}} = C_P(z)\,\mathcal{Z}{\zeta_{h,t}} \tag{5}$$

$$u_t = g_{f,\Gamma_t}(\zeta_{f,t}) \tag{6}$$

여기서: - $g_{h,\Gamma_t}: \mathbb{R}^3 \to \mathbb{R}^{n_h}$ — Pre-control map (MLP): $h$의 유사 역함수 - $C_P(z)$ — Delay-tracking system (IIR unit): $n_f \times n_h$ LTI 전달함수 - $g_{f,\Gamma_t}: \mathbb{R}^{n_f} \to [-1,1]^3$ — Post-control map (PL map 유사역함수): $\text{PL}^+{\Phi{f,t}}$

Delay-tracking 조건 (최종값 정리, reference tracking):

$$\lim_{z \to 1} (z-1)\big(P(z)C_P(z) - I_{n_h}\big)\,\mathcal{Z}{t^{n_r}} = 0_{n_h \times n_h} \tag{7}$$

  • $n_r = 0$: step reference 추종
  • $n_r = 1$: ramp reference 추종

3.3 P 제어를 통한 강건성 확보

$$\omega_t^{\text{cmd}} := \omega_t^{\text{ref}} - K\,e_{\theta,t} \tag{8}$$

여기서: - $\omega_t^{\text{ref}} \in \mathbb{R}^3$: 레퍼런스 관절 각속도 - $e_{\theta,t} := \theta_t - \theta_t^{\text{ref}} \in \mathbb{R}^3$: 관절 각도 오차 - $K \in \mathbb{R}^{3 \times 3}$: P 게인 (양정치 행렬, 실험에서 $K = 1.5 I_3$)

flowchart LR
    TP[궤적 계획기] --> |"θ_ref, ω_ref"| PC[P Control<br/>Eq.8]
    SENSOR[센서 측정<br/>θ_t] --> PC
    PC --> |"ω_cmd"| INV[모델 역변환<br/>Eq.4→5→6]
    STATE["Γ_t"] --> INV
    INV --> |"u_t"| EXC[굴착기]
    EXC --> SENSOR
    EXC --> ENV[환경/토양]
    ENV --> |"F_ext"| STATE

3.4 안정성 분석

Proposition 1 (유계성, Boundedness): 가정: (a) 모델 예측 오차 $\delta_{\omega,t}$, 유사 역함수 오차 $\delta_{h,t}$, $\delta_{f,t}$가 유계; (b) $h_{\Gamma_t}$가 Lipschitz 연속; (c) $g_{h,\Gamma_t}$가 유계 함수 → $\nu_{\omega,t} := \omega_t - \omega_t^{\text{cmd}}$는 $\forall t \geq t_0$에서 유계.

증명 핵심: BIBO 안정성과 class $\mathcal{KL}$ 함수를 이용하여 $|\eta_{h,t} - \zeta_{h,t}|$의 유계성 확보

$$|\eta_{h,t} - \zeta_{h,t}| \leq \beta(|\eta_{h,t_0} - \zeta_{h,t_0}|,\, t-t_0) + \gamma_1!\left(\sup_{t_0 \leq \tau \leq t}|\zeta_{h,\tau}|\right) + \gamma_2!\left(\sup_{t_0 \leq \tau \leq t}|\delta_{f,\tau}|\right)$$

Theorem 1 (궁극적 유계성, Ultimate Boundedness): P 제어 (8)하에서 Lyapunov 함수 $V = \frac{1}{2}e_{\theta,t}^\top e_{\theta,t}$를 사용하여:

$$\dot{V} = e_{\theta,t}^\top \dot{e}{\theta,t} = -e{\theta,t}^\top K\,e_{\theta,t} + e_{\theta,t}^\top \nu_{\omega,t}$$

$$\dot{V} \leq -\lambda_{\min}(K)|e_{\theta,t}|^2 + |e_{\theta,t}||\nu_{\omega,t}|$$

→ 관절 각도 오차가 반경 $|\nu_{\omega,t}|/\lambda_{\min}(K)$의 폐구에 의해 궁극적으로 유계됨.

기존 데이터 기반 굴착기 제어 연구([7]-[10])에서는 제공하지 못한 이론적 안정성/강건성 보장

4. 신경망 모듈 상세 및 학습 과정

4.1 IIR Unit (Infinite Impulse Response Unit)

z-도메인 SISO LTI 전달함수:

$$H(z) = \frac{b_0 + b_1 z^{-1} + \cdots + b_{n_b} z^{-n_b}}{a_0 + a_1 z^{-1} + \cdots + a_{n_a} z^{-n_a}}$$

차분 방정식을 정규화하여 재배열:

$$y_t = \sum_{i=1}^{n_b} \bar{b}i(x{t-i} - x_t) - \sum_{i=1}^{n_a} \bar{a}i(y{t-i} - DC_H \cdot x_t) + DC_H \cdot x_t$$

여기서: - $\bar{b}_i := b_i / a_0$, $\bar{a}_i := a_i / a_0$: 정규화 계수 (학습 가능 파라미터) - $DC_H := H(1)$: DC 이득 (저주파 이득)

구현 사양: - $P(z)$: $3 \times 3$ IIR unit - 대각 성분: 3차 전달함수 ($n_b^{jk} = n_a^{jk} = 3$, $j = k$) - 비대각 성분: 0 ($n_b^{jk} = n_a^{jk} = 0$, $j \neq k$) - $DC_P := P(1)$: 대각이 1, 비대각이 0인 행렬

IIR unit 없이 학습된 제어기는 실기에서 치명적 진동(fatal oscillation) 발생

4.2 Piecewise Linear (PL) Map

단조 비감소(monotonically non-decreasing) n-segment PL map:

$$\text{PL}{(\mathcal{X},\mathcal{Y})}(x) = \frac{(Y_i - Y{i-1})x + X_i Y_{i-1} - X_{i-1} Y_i}{X_i - X_{i-1}}, \quad x \in [X_{i-1}, X_i)$$

  • 연속: $X_{i-1} < X_i$일 때 $\text{PL}(X_i) = Y_i$
  • 불연속(점프) 표현 가능: $X_{i-1} = X_i$일 때 → dead-zone의 점프 보상

유사 역함수: 단조성에 의해 $\text{PL}^+{(\mathcal{X},\mathcal{Y})} = \text{PL}{(\mathcal{Y},\mathcal{X})}$ (X와 Y를 교환)

Custom Activation Function (비감소 시퀀스 학습):

$$d_i = a + (b-a) \frac{\sum_{j=1}^{i} \exp(c_j)}{\sum_{j=1}^{n} \exp(c_j)}, \quad \forall i \in {1, 2, \ldots, n}$$

  • 입력: $c \in \mathbb{R}^n$ → 출력: $d = (a, d_1, \ldots, d_n) \in [a, b]^{n+1}$, 비감소 순서 보장

구현 사양: - Boom, Arm, Bucket 각각 8-segment PL map (3개 독립) - 보조 네트워크 $\phi_f$: hidden 64 ReLU → output $8 \times 6$ with $\sigma_{[-1,1]}$ - 경계 breakpoint: $X_0^k = Y_0^k = -1$, $X_{n_k}^k = Y_{n_k}^k = 1$

4.3 Post-delay Map (MLP)

  • 단일 은닉층 256 ReLU 노드 + 선형 출력층
  • 잔여 비선형성 및 관절 간 커플링 처리

4.4 오프라인 학습 과정

Plant Model 학습

$$\mathcal{L}^{\text{plant}} := |\hat{\omega}_t - \omega_t|^2$$

  • $P(z)$, $f$, $h$ 모두 학습 가능
  • Adam optimizer, 약 2시간 수렴
  • 테스트 데이터 예측 RMSE: (0.51, 0.66, 1.16) [deg/s] (boom, arm, bucket)

Inversion Control 학습

$g_f$ (Post-control map): $\text{PL}^+{\Phi{f,t}}$로 분석적으로 계산 → 학습 불필요

$C_P(z)$ (Delay-tracking system): 분석적으로 구성 - 학습된 $P(z)$의 불안정 영점 → 정확한 역함수 불존재 - Reference tracking 조건 (7)을 $n_r \in {0, 1}$에 대해 충족 - 극점: 0.82 (중복도 2)로 경험적 최적화

$g_h$ (Pre-control map): Distal learning [16]

$$\mathcal{L}h^{\text{inv}} := |\check{\omega}_t - \omega_t|^2, \quad \check{\omega}_t := (h{\Gamma_t} \circ g_{h,\Gamma_t})(\omega_t)$$

  • 은닉층 256 ReLU + 출력층 tanh (유계 출력 보장)
  • 5분 미만으로 학습 완료 (모듈형 역변환의 이점)

7. 한계 및 향후 연구

7.1 현재 한계

  • Sagittal plane (2D) 운동만 고려 — Swing 동작 미포함
  • LTI 전달함수 $P(z)$ 사용 — 상태 의존 지연 미반영 (저자도 가능하다고 언급하나 미적용)
  • 특정 작업(굴삭/그레이딩)에 대해서만 검증 — 전체 작업 공간 미검증
  • 오프라인 학습만 가능 — 새로운 환경 적응을 위해 재학습 필요

7.2 저자 제시 향후 방향

  1. 상태 의존 지연 시스템으로 Plant Model 일반화
  2. 전문가 모방 궤적 계획 [15] 통합
  3. OTA(Over-the-Air) 프로그래밍으로 데이터 수집/제어 업데이트 효율화
  4. 다른 제어 전략과의 체계적 비교 (e.g., Bayesian optimization [17])
  5. 지연과 dead-zone이 있는 다른 시스템으로의 확장 적용

8. 한마디로 정리

  • 물리 기반 모듈형 구조 (IIR + PL + MLP)로 유압 굴착기의 입력 지연, dead-zone, 비선형 동역학을 분리 학습 → 파라미터 9,160개로 효율적 구현
  • 모듈형 역변환으로 학습 시간 대폭 단축 (plant 2시간 + inversion 5분) → 기존 RL 대비 5배 이상 빠른 학습 달성
  • Lyapunov 기반 안정성 증명 (Proposition 1 + Theorem 1) → 기존 데이터 기반 굴착기 제어에서 미제공된 이론적 보장 구현
  • 38톤급 상용 굴착기(Doosan DX380LC)에서 RMSE < 2 cm 달성 → PI 제어 대비 65% 이상 개선 달성
  • 산업용 속도(66-87 cm/s)와 큰 토양 외력(~6.4 x 10^4 N) 조건에서 정밀 제어 구현
  • Swing 동작, 상태 의존 지연, 전체 작업 공간으로의 확장은 미대응
