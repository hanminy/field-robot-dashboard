ETH 자율굴착 논문 카드 요약 2014-2026

[!note] 2014 · 로봇 중심 확률 고도지도 1) 대표그림

2) 요약

거리센서와 자세 추정의 불확실성을 셀별로 융합하고 지도를 로봇과 함께 이동시켜, 위치 드리프트에도 일관된 국소 고도지도를 생성

3) 방법

  1. 거리 측정값을 로봇 좌표계의 높이와 분산으로 변환
  2. 자세 공분산과 센서 잡음을 반영해 각 격자의 높이를 확률적으로 갱신
  3. 로봇 이동량만큼 지도를 옮기고 필요한 셀만 병렬 융합

4) 토의

  • 한계: 단일 표면의 2.5D 지도이며 소형 4족 보행로봇에서만 검증
  • 연구주제: 굴착으로 지형이 사라지거나 가려질 때 작업 상태를 이용해 셀 불확실성을 갱신하는 지도를 연구

[!note] 2016 · ROS 다층 Grid Map 1) 대표그림

2) 요약

고도·분산·색상 등 여러 격자층을 원형 버퍼로 관리하며 이동로봇의 실시간 지형 처리에 재사용할 수 있는 ROS 라이브러리

3) 방법

  1. Eigen 행렬 기반 GridMap에 필요한 데이터층과 좌표계를 정의
  2. 로봇 이동 시 원형 버퍼의 경계만 이동해 기존 셀을 재활용
  3. 영역 iterator와 filter chain으로 고도지도·법선·주행성을 계산

4) 토의

  • 한계: 2.5D 자료구조 구현이 중심이며 복수 표면과 동적 지형의 처리 정책은 미제공
  • 연구주제: 고도·토질·압력·작업완료도를 한 지도에서 갱신하는 굴착 전용 다층 Grid Map을 개발

[!note] 2016 · IBEX 굴착기 원격조작 플랫폼 1) 대표그림

2) 요약

굴착기 자세를 3자유도 모션 플랫폼과 3면 영상으로 재현, 위험 현장 원격조작·운전자 훈련 지원

3) 방법

  1. 실기 또는 Vortex 시뮬레이터에서 차체 roll·pitch·yaw를 수신
  2. 차동 레버 두 개와 회전 베어링으로 조종석 자세를 재현
  3. 굴착기 조이스틱과 3면 영상을 연결해 동일 작업을 원격 수행

4) 토의

  • 한계: 소규모 시뮬레이터 평가, 실기 통신지연·3D 상황인지 미검증
  • 연구주제: 영상·음향·유압 하중의 지연을 보상하는 예측형 멀티모달 굴착기 원격조작을 연구

[!note] 2016 · 거친 지형 계층형 주행계획 1) 대표그림

2) 요약

경사·거칠기·단차와 로봇 발자국을 평가한 주행성 지도에서 계층형 RRT*가 안전하고 짧은 거친 지형 경로를 탐색

3) 방법

  1. 고도지도에서 경사·거칠기·단차를 계산해 주행성 지도를 생성
  2. 원형·다각형 발자국을 단계적으로 적용해 전역 RRT* 경로를 탐색
  3. 새 지형 관측 시 단거리 계획기로 경로 반복 보정

4) 토의

  • 한계: StarlETH 중심의 저속 지도와 기하 규칙이라 대형 장비의 전복·슬립 위험은 미고려
  • 연구주제: 굴착기 차체 자세와 지지다각형을 비용으로 넣은 장비별 3D 주행계획기를 연구

[!tip] 2017 · 힘 기반 굴착 계획·제어 · 🧪 재현 추천 1) 대표그림

2) 요약

토양 모델 없이 버킷 힘·토크 궤적으로 한 번의 굴착을 제어하고, 반복 계획기가 목표 지형까지 공격점과 덤프점을 갱신

3) 방법

  1. 관입·끌기·닫기 구간의 버킷 힘·토크 기준을 정의
  2. 계층형 최적화로 힘과 자세를 추종하며 관절 한계와 여유자유도를 처리
  3. 고도 오차에서 공격점·덤프점 재선정, 목표 형상까지 반복

4) 토의

  • 한계: 다중 굴착 결과가 시뮬레이션에 머물고 큰 돌에 대한 복구 동작이 부재
  • 연구주제: 실차 압력·속도로 장애물 접촉을 판별하고 우회 공격점을 재계획하는 힘 기반 굴착기를 연구

[!note] 2017 · 실시간 의미 지형지도 · 외부 기반기술 1) 대표그림

2) 요약

RGB 의미분할과 LiDAR 고도를 2.5D 지도에 융합해 길·풀·장애물을 구분하고 오프로드 차량의 경로 비용으로 활용

3) 방법

  1. 오프로드 영상을 주석화해 경량 FCN 의미분할망을 학습
  2. 픽셀 클래스를 LiDAR 점군에 투영해 고도·의미 격자를 갱신
  3. 후보 경로의 의미별 통과 비용을 계산해 최적 경로를 실행

4) 토의

  • 한계: 수작업 라벨과 ATV 단일 데이터에 의존해 먼지·계절·새 현장 일반화가 어려움
  • 연구주제: 작업 중 수집되는 LiDAR와 주행 반응으로 라벨 없이 적응하는 건설현장 의미지도를 연구

[!note] 2018 · 드리프트 강건 확률 지형지도 1) 대표그림

2) 요약

고유감각 위치추정 드리프트의 로봇 중심 전파, 고도 셀별 상·하 신뢰구간 제공

3) 방법

  1. 거리센서 측정과 자세 공분산으로 셀별 높이·분산을 갱신
  2. 로봇 이동 불확실성에 따라 기존 지도 분포를 공간적으로 전파
  3. 데이터 수집과 지도 융합을 분리해 실시간으로 신뢰구간을 출력

4) 토의

  • 한계: 지형이 정적이고 단일 높이라고 가정, 굴착 중 급격한 변화·가림 구분 불가
  • 연구주제: 버킷 작업영역의 셀을 동적 상태로 전환해 측정 누락과 실제 굴착 변화를 분리

[!tip] 2019 · 자율 자유형 트렌칭 · 🧪 재현 추천 1) 대표그림

2) 요약

작업 인지형 고도지도, 충돌회피 궤적, 힘 기반 굴착 상태기를 HEAP에 통합해 자유곡선 도랑을 실차로 정밀 굴착

3) 방법

  1. LiDAR 지도에 버킷 경로와 가림·낙토 정보를 반영해 지형을 갱신
  2. 목표 지형에서 공격점을 고르고 SQP로 충돌 없는 접근·이탈 경로를 생성
  3. 힘 기반 관입·끌기·닫기 실행, 고도 오차 수렴까지 반복

4) 토의

  • 한계: 단일 장비의 통제된 트렌칭이며 큰 장애물과 장시간 작업 복구는 미검증
  • 연구주제: 돌·뿌리 접촉을 감지해 공격 방향과 작업 순서를 바꾸는 자율 복구 상태기를 연구

[!note] 2019 · 굴착기 전신 동작계획 1) 대표그림

2) 요약

차체·관절·바퀴 접촉일정을 동시에 최적화해 주행과 보행을 섞어 거친 지형을 통과하는 전신 궤적을 생성

3) 방법

  1. 차체·말단 위치·관절·접촉시간을 Hermite spline 변수로 설정
  2. 지형높이·지지다각형·무슬립·관절범위를 NLP 제약으로 구성
  3. 초기 접촉일정을 넣고 IPOPT로 전신 궤적과 구간시간을 함께 최적화

4) 토의

  • 한계: 계산량이 커 오프라인 계획 중심이고 실제 센서오차와 지반 슬립 검증이 부족
  • 연구주제: 이전 해와 국소 지형을 재사용해 전신 접촉계획을 실시간 MPC로 갱신

[!note] 2020 · 자율 건식 석벽 시공 1) 대표그림

2) 요약

굴착기 LiDAR로 불규칙 석재를 현장에서 스캔하고 매 배치 직전 형상을 계획해 40개 돌로 3m 높이의 건식 석벽을 시공

3) 방법

  1. 주변 돌과 벽을 LiDAR로 지도화하고 개별 석재의 3D 모델을 생성
  2. 목표 벽과 현재 시공 오차에서 다음 돌의 안정 배치 자세를 계산
  3. 그리퍼로 돌을 집어 배치하고 재스캔한 결과로 다음 계획을 갱신

4) 토의

  • 한계: 석재 40개와 단일 벽 검증이며 스캔·계획·배치 시간이 길고 특수 그리퍼가 필요
  • 연구주제: 빠른 부분형상 추정과 학습 기반 안정도 예측으로 석재 선택·배치 시간을 단축

[!note] 2020 · 지형 적응 전신 계획·제어 1) 대표그림

2) 요약

궤적최적화와 계층형 전신제어의 결합, HEAP 토크·속도 관절을 이용한 주행·보행

3) 방법

  1. 지형·목표 자세에서 차체·바퀴·접촉 궤적 오프라인 최적화
  2. WBC가 접촉 관절 토크를, IK가 비접촉 관절 속도를 계산
  3. 100Hz 차체·말단 추종, 미관측 요철 순응

4) 토의

  • 한계: 계획은 오프라인이고 관성·유압 대역폭을 단순화해 빠른 동작에는 적용하기 어려움
  • 연구주제: 유압 지연과 지반 접촉을 포함한 짧은 지평선 전신 MPC를 실차에서 구현

[!tip] 2020 · 데이터 기반 유압 RL 제어 · 🧪 재현 추천 1) 대표그림

2) 요약

실차 데이터로 유압 액추에이터 모델을 학습하고 그 모델 안에서 RL 제어기를 훈련해 밸브 명령을 실차에 바로 전이

3) 방법

  1. 4개 팔 관절 상태·밸브 명령·엔진·오일온도의 100Hz 수집
  2. 과거 상태에서 다음 관절속도를 예측하는 신경 액추에이터 모델을 학습
  3. 모델 시뮬레이터에서 말단 추종 정책을 RL로 훈련해 실차 밸브에 배치

4) 토의

  • 한계: 단일 장비의 자유공간 위치추종 중심이라 접촉하중과 장비 노화에 대한 강건성이 불명확
  • 연구주제: 작업 중 압력 오차로 액추에이터 모델을 온라인 보정하는 지속학습형 유압 제어를 연구

[!tip] 2021/2022 · 범용 유압 굴착기 팔 RL · 🧪 재현 추천 1) 대표그림

2) 요약

실차로 학습한 유압 모델과 RL 정책만으로 장비별 수작업 게인 조정 없이 말단 속도·궤적을 정밀 추종

3) 방법

  1. 관절·밸브·엔진·온도 이력으로 다관절 유압 동역학 모델을 학습
  2. 링크 길이와 학습 모델로 시뮬레이터를 만들고 말단 속도 추종 정책을 훈련
  3. 정책 출력을 pilot-stage 밸브에 직접 보내 자유공간과 토양 접촉 궤적을 실행

4) 토의

  • 한계: 새 장비마다 데이터 수집·모델 재학습 필요, 명시적 안전 보장 부재
  • 연구주제: 소량 장비 데이터와 제어 장벽함수로 빠르고 안전하게 전이되는 유압 정책을 개발

[!note] 2021 · 자율 자유형 지형 조성 1) 대표그림

2) 요약

드론 측량·재료중립 설계·HEAP 굴착을 폐루프로 연결해 현장 토사만으로 자유곡면 제방을 자동 조성

3) 방법

  1. LiDAR 드론으로 현장을 측량해 2.5D 고도지도를 생성
  2. Rhino 설계에서 절토·성토량을 맞춘 목표 지형과 작업선을 계산
  3. HEAP가 굴착점·덤프점을 반복 선택하고 실측 고도로 설계를 갱신

4) 토의

  • 한계: 한 대의 장비와 제한된 토질에서 장시간 수행했으며 설계·주행·굴착의 공동 최적화는 아님
  • 연구주제: 여러 장비의 이동·절토·성토 순서를 함께 최적화하는 폐루프 토공 계획을 연구

[!note] 2021 · 석재 파지·재정렬 계획 1) 대표그림

2) 요약

석재 점군에서 충돌 없는 force-closure 파지를 고르고 직접 배치가 어렵다면 물리 시뮬레이션으로 중간 재정렬 자세를 탐색

3) 방법

  1. LiDAR 점군·복원 mesh에서 그리퍼 파지 후보 대량 생성
  2. 충돌·접근방향·감싸기·무게중심 비용으로 후보 필터링
  3. 직접 배치가 불가능하면 안정 중간자세를 시뮬레이션해 재파지 후 배치

4) 토의

  • 한계: 정확한 석재 복원·특수 2지 그리퍼 의존, 파지 중 미끄러짐 폐루프 보정 부재
  • 연구주제: 손목 힘과 부분 점군으로 미끄러짐·자세 오차를 보정하는 폐루프 석재 조작을 연구

[!note] 2021 · HEAP 자율 보행 굴착기 1) 대표그림

2) 요약

상용 12톤 보행 굴착기에 센서·전기유압 구동·상태추정·차체·팔 제어를 통합한 자율 건설로봇 플랫폼

3) 방법

  1. GNSS·IMU·LiDAR·실린더 센서와 3종 밸브·조이스틱 구동 장착
  2. 센서융합으로 차체·관절 상태를 추정하고 CAN·공유메모리 제어 계층을 구성
