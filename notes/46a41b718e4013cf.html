1. 연구 배경 및 동기

문제

  • 건설 현장의 노동력 부족, 인건비 상승, 안전 위험

3.1 2.5D 높이맵

작업 영역을 40cm × 40cm 격자로 분할하고, 각 셀 $c$에 높이의 기대값 $\hat{x}_c$과 분산 $\hat{\sigma}_c^2$을 관리한다. 전체 3D가 아닌 2.5D를 쓰는 이유는, 건설 지형은 각 수평 위치에 높이가 하나이므로 셀당 스칼라 높이면 충분하기 때문이다.

3.3 칼만 필터형 MAP 추정

지형 동역학 모델 (식 1):

지형의 높이가 시간에 따라 변할 수 있다고 가정하는 확률적 동역학 모델:

$$x_{k+1}^c = \begin{cases} x_{\text{bucket}}^c + u_k^c & \text{(버킷이 지면 아래로 통과한 경우)} \ x_k^c + w_k^c & \text{(그 외)} \end{cases}$$

기호 의미
$x_k^c$ 시각 $t_k$에서 셀 $c$의 높이
$x_{\text{bucket}}^c$ 버킷 팁이 지나간 높이 (굴착 시 지형이 깎임)
$u_k^c$ 굴착 후 노이즈 ~ $\mathcal{N}(0, Q_u)$
$w_k^c$ 자연 변화 노이즈 ~ $\mathcal{N}(0, Q_w)$ (미세 산사태 등)

직관: $Q_u$, $Q_w$가 작으면 "지형이 잘 안 변한다"고 가정 → 이전 추정값을 더 신뢰. $Q_u$, $Q_w$가 크면 지형 변화가 잦다고 가정 → 최신 센서 측정값에 더 의존.

측정 모델 (식 2):

$$y \sim \mathcal{N}!\left(x_k^c, \; v + C \cdot d^2\right)$$

기호 의미
$y$ 라이다 높이 측정값
$x_k^c$ 셀 $c$의 실제 높이 (추정 대상)
$v \geq 0$ 라이다 거리 측정 분산 (센서 스펙에서 제공)
$C \geq 0$ 지형 최대 기울기 관련 파라미터
$d$ 라이다 점에서 셀 중심까지의 수평 거리

직관: 셀 중심에서 멀리 떨어진 점일수록 해당 셀의 높이를 대표하기 어렵다 ($C \cdot d^2$ 항). 경사면에서는 40cm만 벗어나도 높이가 크게 달라질 수 있기 때문.

MAP 추정 과정:

각 셀에 높이의 기대값과 추정 분산을 함께 관리한다 (초기값: 분산 무한대, 기대값 0). 매 업데이트마다, 이전 시점 $t_k$의 추정값과 $t_k \sim t_{k+1}$ 사이에 들어온 라이다 점들을 결합하여 MAP(최대 사후 확률) 추정을 수행한다. 이렇게 구한 MAP 평균 $\hat{x}{k+1}^c$이 시각 $t{k+1}$에서의 지형 정보로 사용되어 충돌 회피 및 굴착 경로 생성에 활용된다.

📐 보충 수식 (논문에 명시되지 않은 유도 수식)

위 동역학(식 1) + 측정(식 2) 모델에 표준 칼만 필터 프레임워크를 적용하면, MAP 업데이트는 다음과 같이 유도된다:

$$\hat{x}_{k+1}^c = \frac{\frac{1}{\hat{\sigma}_k^2} \cdot \hat{x}_k + \sum_i w_i \cdot y_i}{\frac{1}{\hat{\sigma}_k^2} + \sum_i w_i}, \quad w_i = \frac{1}{v + C \cdot d_i^2}$$

이전 추정값과 새 측정값의 신뢰도(분산의 역수) 가중 평균으로, 셀 중심에 가까운 점($d_i$↓)일수록 가중치 $w_i$가 크다.

출처: 식 (1), (2)에 표준 칼만 필터 MAP 업데이트 규칙을 적용하여 유도

# 칼만 필터형 MAP 업데이트 의사코드
for cell in heightmap:
    # 예측 단계: 동역학 모델 (식 1) 적용
    if bucket_swept_cell(cell, t_k, t_k1):
        x_pred = bucket_tip_height(cell)
        var_pred = Q_u
    else:
        x_pred = cell.height      # 이전 추정값 유지
        var_pred = cell.variance + Q_w  # 불확실성 증가

    # 업데이트 단계: 새 라이다 측정값들로 MAP 추정
    for p in filtered_points_in_cell(cell):
        d = horizontal_distance(p, cell.center)
        R = v + C * d * d          # 측정 분산 (식 2)
        K = var_pred / (var_pred + R)  # 칼만 게인
        x_pred = x_pred + K * (p.z - x_pred)
        var_pred = (1 - K) * var_pred

    cell.height, cell.variance = x_pred, var_pred

일반 굴착 (Normal Digging)

  • 목표: 매 사이클에서 버킷 용량(1m³)에 근접한 최대 부피 굴착
  • 방법: 3D 격자(붐/스틱/버킷 실린더 길이)에서 DFS(깊이 우선 탐색)
  • 공격점(Point of Attack): 현재 지형과 팁 그레이딩 임계값의 교점 중 캐빈에서 가장 먼 점
  • 우선순위 휴리스틱: 예상 굴착 부피↑ + 예상 파워 소비↓ (하드웨어 특화)
  • 실행 가능성 체크: 버킷 용량 초과 여부, 절삭각(팁 경로와 버킷 각도), 팔 관통 여부
# DFS 기반 일반 굴착 경로 탐색 의사코드
def find_digging_path(landscape, target):
    root = find_point_of_attack(landscape, target)  # 가장 먼 교점
    stack = [root]
    while stack:
        node = stack.pop()  # DFS: 후입선출
        if is_feasible(node):  # 용량, 절삭각, 관통 체크
            if excavated_volume(node) >= target_volume:
                return path_to(node)
        children = expand(node)  # 실린더 길이 한 스텝 변경
        children.sort(key=lambda n: heuristic(n))  # 부피↑ + 파워↓
        stack.extend(children)

400 팁 그레이딩 동작 상세: 목표 지형을 따라 버킷 팁으로 표면을 정밀하게 다듬는 과정

팁 그레이딩 (Tip Grading)

  • 목표: 목표 지형을 따라 표면 정밀 다듬기
  • 방법: 목표 지형의 가장 먼 도달 가능 점에서 시작 → 일정 절삭각 유지하며 캐빈 방향으로 당김
  • 전환 조건: 높이 오차 ≤ 50cm
  • 팁 그레이딩 후에도 오차가 크면 재굴착+재그레이딩 반복

4.4 A* 경로 계획 (Phase 1, 3, 4, 5)

  • 탐색 공간: 4D 격자 (스윙 각도 + 3 실린더)
  • 목적함수: 각 실린더의 유입/유출 유량 합 최소화 → 에너지 효율
  • Phase 4 추가 제약: 버킷 개구부가 아래를 향하는 configuration → 장애물 취급 (흙 유출 방지)

5. MPC 기반 경로 추적

5.1 왜 MPC가 필요한가

경로(Path)에는 시간 정보가 없다. "어디를 지나가라"만 있고 "얼마나 빨리"가 없다. MPC는 시간을 배분하면서 동시에 물리적 제약을 실시간으로 만족시킨다.

5.2 동역학 모델 (식 3)

1차 이산 시간 기구학 모델: $$q_{k+1} = f_d(q_k, u_k)$$

변수 차원 의미
$q$ $\mathbb{R}^4$ configuration: 스윙 각도 + 3개 실린더 길이
$u$ $\mathbb{R}^4$ 제어 입력: 스윙 속도 + 3개 실린더 신축 속도
$f_d$ - 이산 시간 상태 전이 함수

기구학 관계: $\dot{q} = J(q) \cdot u$, 여기서 $J(q)$는 자코비안 행렬.

설계 선택: 고차 유압 동역학 모델(압력, 관성 포함)은 유온(oil temperature)/마찰 불확실성이 크고 비선형성이 강해 실시간 MPC 적용이 어렵다. 대신 1차 기구학 모델 + 충분한 성능의 저수준 제어기 조합이 실용적이며, 실험으로 유효성을 검증했다.

5.3 물리적 제약 (식 4)

$$c(q_k, u_k, f_p) \leq 0$$

기호 의미
$f_p$ 유압 실린더 내부 압력 측정값 (파워 제약 계산에 사용)
$c(\cdot)$ 물리적 제약 함수 (3가지 제약을 벡터로 결합)

논문에서 고려하는 3가지 물리적 제약: 1. 파워 한계 (Power limit) 2. 실린더 변위 한계 (Cylinder displacement limit) 3. 펌프 유량 한계 (Pump flow rate limit)

📐 보충 수식 (논문 [15]에 상세 정의, 본 논문에서는 $c(\cdot) \leq 0$으로만 기술)

제약 수식 물리적 의미
파워 한계 $\sum_i p_i \cdot \dot{l}i \leq P{max}$ 유압 펌프 최대 출력
실린더 변위 $l_{min} \leq l_i \leq l_{max}$ 각 실린더 스트로크 범위
펌프 유량 $\sum_i A_i \cdot \dot{l}_i

출처: 저자 이전 연구 [15]에서 상세 정의

5.4 MPC 최적화 문제 (식 5)

$$\min_{q_{(\cdot)}, \, u_{(\cdot)}} J(q_r, u; \, q_{(\cdot)})$$

제약 조건: | 제약 | 수식 | 의미 | |------|------|------| | 동역학 (식 3) | $q_{k+1} = f_d(q_k, u_k)$ | 물리 법칙 | | 초기 상태 | $q_0 = q(t)$ | 현재 위치 | | 물리적 제약 (식 4) | $c(q_k, u_k, f_p) \leq 0$ | 파워, 유량, 변위 한계 |

비용함수 $J$는 상태 오차 $q - q_r$과 제어 입력 $u$에 대한 이차 형식(quadratic)이며, Augmented Lagrangian 방법 기반 제약 iLQR [20]로 실시간 풀이한다.

📐 보충 수식 (논문에서 "quadratic with respect to $q - q_r$ and $u$"로만 기술)

$$J = \sum_{k=0}^{N-1} \left[ (q_k - q_{r,k})^\top Q \, (q_k - q_{r,k}) + u_k^\top R \, u_k \right]$$

  • Q 행렬: 참조 경로 $q_r$로부터의 편차 벌점 → 추적 정밀도 결정
  • R 행렬: 과도한 제어 입력 억제 → 부드러운 동작 보장
  • $f_p$: 유압 압력 측정값. 예측 구간 동안 상수로 가정하고 빠른 업데이트율(<0.08s)로 보상

출처: 표준 이차 비용함수(LQR) 형태로 유도

5.5 시간 배분

  • 경로 세그먼트별 이동 시간 = 각 실린더의 기준 신축 속도를 초과하지 않는 최대 시간(느리게 갈수록 안전)
  • MPC가 이 기준 시간을 따르되, 물리적 제약에 의해 실시간 조절

6.3 2-Step BA (핵심 혁신)

문제: Full BA는 모든 카메라 포즈(6DoF × N장)와 모든 3D 점(3 × M개)을 동시 최적화. M이 수백만이면 포즈-점 커플링 항으로 계산 폭발.

핵심 통찰: 카메라 포즈를 정확히 결정하는 데 수백만 점은 필요 없다. 수천 개면 충분하다.

Step 최적화 대상 점 개수 포즈 특징
1 포즈 + 점 동시 ~수천 (FAST score 상위) 자유 포즈 결정에 충분
2 점만 수백만 전체 고정 커플링 없음 → 빠름

정밀도 손실은 Full BA 대비 무시할 수 있는 수준이며, 계산 속도는 수십 배 향상.

6.4 라이다 사전 정보 활용

라이다 높이맵 → 특징점 3D 위치 초기값 제공 → BA 수렴 속도·안정성 향상. 라이다(대략적, 빠름) + 카메라(정밀, 느림)의 센서 퓨전 효과.
