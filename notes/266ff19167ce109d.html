(한민확인) Expert-Emulating Excavation Trajectory Planning for Autonomous Robotic Industrial Excavator

한줄 요약

숙련 운전자의 굴착 궤적과 힘 패턴을 DMP(Dynamic Movement Primitives) + MLP 신경망으로 학습하고, 실시간 굴착력 피드백을 통한 Coupling Movement Primitives 기반 온라인 궤적 변조로 안전성과 강건성을 확보한, 산업용 자율 로봇 굴삭기(Doosan DX380LC)에서의 전문가 모사 굴착 궤적 계획 프레임워크.

1. 연구 배경 (Introduction)

1.1 문제 정의

  • 굴삭기는 건설 현장에서 가장 광범위하게 사용되는 중장비이나, 숙련 운전자 확보가 점점 어려워지고 있음
  • 토양 역학(soil dynamics)은 너무 복잡하여 실시간 제어에 활용할 수 있을 정도의 컴팩트한 모델로 포착하기 어려움
  • 기존 연구들은 토양 상호작용을 고려하지 않거나, 단순 직선/고정 형상 궤적만 다룸 → 전문가 수준의 복잡한 굴착 궤적 생성 불가

1.3 본 논문의 접근

  • 데이터 기반/학습 기법 채택: 전문가 운전자의 행동을 모사
  • DMP로 궤적 인코딩 → 궤적의 질적 형상 보존 + 종점 수렴 보장 + 높은 데이터 효율성
  • MLP로 DMP의 shaping force 학습 → 전문가 모사
  • Coupling Movement Primitives로 실시간 힘 기반 궤적 변조 → 안전성 확보

3. 핵심 기술 (Methodology)

3.1 Dynamic Movement Primitives (DMP)

DMP는 단위 질량의 임계 감쇠 시스템(critically-damped system)에 비선형 외력을 가하여 궤적을 표현하는 방법이다.

클럭 신호 (Canonical System)

$$\tau \dot{s} = -\alpha_s s \tag{1}$$

  • $s \in [0, 1]$: 클럭 신호 ($s(0)=1$, 단조감소)
  • $\tau > 0$: 시간 스케일링 파라미터
  • $\alpha_s > 0$: 감쇠율

DMP 동역학 (각 $p_x$, $p_y$에 대해 독립 적용)

$$\tau \ddot{y} = \alpha_y(\beta_y(y_g - y) - \dot{y}) + f(s) \tag{2}$$

$$f(s) = h(s)(y_g - y_0)s \tag{3}$$

변수 의미
$y_0 \in \mathbb{R}$ 초기점
$y_g \in \mathbb{R}$ 목표점
$\alpha_y, \beta_y > 0$ 감쇠 게인
$f(s) \in \mathbb{R}$ shaping force
$h(s) \in \mathbb{R}$ 비선형 함수 (학습 대상)
$(y_g - y_0)$ 공간 스케일링
$s$ 목표 수렴 보장 (단조감소)

DMP의 핵심 장점: (1) 궤적의 질적 형상 보존, (2) 목표점으로의 수렴 보장, (3) 데이터 효율성이 높아 소량의 전문가 데이터로 학습 가능

3.2 Coupling Movement Primitives (온라인 변조)

DMP에 변조력(modulation force) $C$를 주입하여 실시간 궤적 수정:

$$\tau \dot{z} = \alpha_y(\beta_y(y_g - y) - z) + f(s) + c_2 \dot{C} \tag{4}$$

$$\tau \dot{y} = z + c_1 C \tag{5}$$

  • $c_1, c_2$: 상수 게인
  • 가속도 레벨과 속도 레벨 모두에 coupling term을 추가하여 PD 제어기처럼 작동 → 오버슈트 방지 [19]

3.3 굴착력 추정 (Momentum-based Wrench Estimator)

굴삭기의 동역학:

$$M(\theta)\ddot{\theta} + C(\theta, \dot{\theta})\dot{\theta} + g(\theta) + F_s \text{sgn}(\dot{\theta}) + B\dot{\theta} = \tau_u + \tau_{\text{ext}} \tag{6}$$

변수 의미
$M(\theta) \in \mathbb{R}^{3\times3}$ 양의 정부호 관성 행렬
$C(\theta, \dot{\theta}) \in \mathbb{R}^3$ 원심/코리올리 벡터
$g(\theta) \in \mathbb{R}^3$ 중력 벡터
$F_s \in \mathbb{R}^{3\times3}$ 쿨롱 마찰 행렬
$B \in \mathbb{R}^{3\times3}$ 점성 마찰 행렬
$\tau_u \in \mathbb{R}^3$ 제어 입력 (실린더 압력에서 산출)
$\tau_{\text{ext}} \in \mathbb{R}^3$ 굴착 토크 (추정 대상)

모멘텀 기반 외란 관측기 [20]:

$$\hat{\tau}{\text{ext}} = K_0 \left( p(t) - \int_0^t (\tau_u - \tau\mu - \beta(\theta, \dot{\theta}) + \hat{\tau}_{\text{ext}}) ds - p(0) \right) \tag{7}$$

  • $p(t) = M(\theta)\dot{\theta}$: 일반화 모멘텀
  • $\beta = g(\theta) - C^T(\theta, \dot{\theta})\dot{\theta}$
  • $\tau_\mu = F_s \text{sgn}(\dot{\theta}) + B\dot{\theta}$
  • $K_0$: 관측기 게인 (1차 저역통과 필터 특성)

작업 공간 굴착력: $f_{\text{ext}} = J_{\text{ext}}^{-T} \hat{\tau}{\text{ext}}$ (Jacobian $J{\text{ext}} \in \mathbb{R}^{3\times3}$은 비특이)

3.4 Task Parameters 추출

400 Fig. 3: (a) 전문가 굴착 궤적 데이터 (18세트): 평지 및 2가지 경사면에서의 3회 연속 굴착. (b) 공간 스케일링 동일화를 위해 목표점 $y_g$를 정합한 수정 학습 궤적.

LiDAR 포인트 클라우드에서 지형의 기하학적 특징을 추출:

$$y(x) = ax + b - aH(x_1 - x)(x - x_1) - aH(x - x_2)(x_2 - x) \tag{8}$$

  • $H(w) := \frac{d}{dw}\max(w, 0)$: 헤비사이드 함수
  • $x_1, x_2$: 경사 시작/끝점
  • $a, b$: 경사/오프셋 파라미터
  • 가우시안 함수 $d\exp(-(x-x_o)^2/c)$로 깊이 파라미터 $d$와 최심점 $x_o$ 추출

Task parameters: $T = (\theta_{\text{slope}}, d) = (\tan^{-1}(a), d)$

3.5 전문가 모사 공칭 궤적 학습

400 Fig. 4: 학습(좌) 및 공칭 궤적 생성(우) 아키텍처. 전문가 궤적에서 DMP shaping force를 추출하고, 신경망으로 $(s, T) \to h(s)$ 매핑을 학습.

학습 데이터

  • 평지 + 2가지 경사(20.38도, 28.30도) x 3회 연속 = 총 18세트
  • 800 스텝, 100Hz, 8초 평균 작업 시간으로 정규화

공간 스케일링 정규화 (공통 목표점 산출)

$$\min_{p_g, p_r} \sum_{i=1}^{n} |\ |p_o - p_g| - p_r\ | \quad \text{s.t.} \quad x_l \le p_{gx} \le x_u, \quad y_l \le p_{gy} \le y_u \tag{9}$$

  • $p_g = (p_{gx}, p_{gy})$: 공통 목표점
  • $p_r$: 초기점에서 목표점까지의 공통 거리

신경망 구조

  • 입력: $(s, T)$ → 출력: $h(s)$
  • MLP: 2개 fully-connected 레이어 (64, 16 노드)
  • 강건하고 실무에서 잘 동작하는 것으로 알려진 기법 선택 (안전성 우선)

3.6 버킷 각도 알고리즘 (Retrieving Nominal Trajectory)

400 Fig. 7: 버킷 각도 $\phi$ 정의. (좌) 버킷 치아와 진행 방향이 일치하면 버킷이 지면과 충돌. (우) 충돌을 회피하는 최소 각도.

  • DMP 궤적은 $p_x, p_y$만 지정 → 3-DOF에서 중복성 발생
  • 버킷 각도 $\phi$: 버킷 치아와 궤적 속도 벡터 사이의 최소 각도로 설정
  • 조건: 버킷을 감싸는 가상 삼각형이 지면과 충돌하지 않을 것
  • 가정: 궤적이 지나간 경로의 토양은 모두 제거됨

온라인 궤적 변조 수식

DMP 좌표계(초기점-목표점 연결선이 제1축)에서의 coupling movement primitive:

$$\tau \dot{z} = \alpha_p(\beta_p(g - y) - z) + f(T, s) + c_2 \dot{C}_{DMP} \tag{10}$$

$$\tau \dot{y} = z + c_1 C_{DMP} \tag{11}$$

$$C(s) = \begin{cases} w & \text{if } w > 0 \ 0 & \text{otherwise} \end{cases} \tag{12}$$

여기서 $w = F_{xcv} - F_{\text{threshold}}$ (양의 힘 피드백만 사용)

$$C_{DMP}(s) = \begin{bmatrix} C_x \ C_y \end{bmatrix} = \begin{bmatrix} -C(s)\sin(\theta_{DMP} - \theta_{\text{slope}}) \ C(s)\cos(\theta_{DMP} - \theta_{\text{slope}}) \end{bmatrix} \tag{13}$$

  • $y \in \mathbb{R}^2$: DMP 좌표 상의 $p_x, p_y$
  • $z \in \mathbb{R}^2$: 상태 속도
  • 과도한 굴착력 발생 시 → 지면에 수직인 방향(얕은 방향)으로 궤적 변조

8. 심화 Q&A

Q1. DMP의 핵심 구조 — Canonical System과 동역학 식은 어떻게 작동하는가?

좋습니다! DMP의 핵심 두 요소인 Canonical System과 동역학 식을 직관적으로 풀어보겠습니다.

🎯 DMP의 큰 그림부터

DMP를 한마디로 비유하면:

"스프링에 달린 공이 목표 지점으로 끌려가는데, 가는 도중에 누군가가 옆에서 밀어서 특정 경로를 따라가게 만드는 것"

  • 스프링 + 댐퍼 = 기본 동역학 (식 2의 앞부분) → 목표점으로 수렴
  • 옆에서 미는 힘 = shaping force $f(s)$ (식 2의 뒷부분) → 원하는 궤적 형상 만들기
  • 타이머 = canonical system $s$ (식 1) → "지금 동작의 몇 %쯤 왔나"

1. Canonical System (식 1): "동작의 시계"

$$\tau \dot{s} = -\alpha_s s$$

이게 뭔가?

이것은 동작 진행도를 나타내는 타이머입니다. 복잡한 시간 $t$ 대신, $s$라는 단순한 숫자 하나로 "지금 동작이 어디쯤인지"를 표현합니다.

각 변수의 역할

변수 직관적 의미
$s$ 진행도 카운터. 시작할 때 $s=1$ (0%), 끝날 때 $s \approx 0$ (100%)
$\alpha_s$ 타이머 속도. 클수록 $s$가 빨리 줄어듦
$\tau$ 전체 동작 시간 스케일. 크면 전체가 느려짐

왜 이런 구조인가?

이 미분방정식의 해를 구하면:

$$s(t) = \exp\left(-\frac{\alpha_s}{\tau} t\right)$$

즉, $s$는 지수적으로 감소하는 값입니다:

s값   1.0 ─────╲
              ╲
               ╲
                ╲──────────
      0.0                    → 시간
      [시작]              [끝]

왜 시간 $t$를 직접 안 쓰고 $s$를 쓰나?

  1. 시간 독립성: $\tau$만 바꾸면 같은 형상의 궤적을 빠르게/느리게 실행 가능
  2. 수렴 보장: $s \to 0$이면 shaping force $f(s)$도 $\to 0$ → 결국 목표점에 반드시 수렴
  3. 단순함: 모든 궤적이 $s \in [1, 0]$ 구간으로 정규화됨 → 비교·학습이 쉬움

📌 핵심: Canonical system은 "지금 동작의 몇 %인지"를 알려주는 단조감소 클럭 신호입니다. 이 클럭이 0에 가까워지면, 외력(shaping force)이 자연스럽게 사라지고 시스템은 목표점에 안착합니다.

2. DMP 동역학 (식 2): "스프링-댐퍼 + 외력"

$$\tau \ddot{y} = \underbrace{\alpha_y(\beta_y(y_g - y) - \dot{y})}{\text{스프링-댐퍼 (목표 수렴)}} + \underbrace{f(s)}{\text{shaping force (형상 결정)}}$$

Part A: 스프링-댐퍼 부분

$\alpha_y(\beta_y(y_g - y) - \dot{y})$를 풀어쓰면:

$$\underbrace{\alpha_y \beta_y (y_g - y)}{\text{스프링: 목표로 당김}} - \underbrace{\alpha_y \dot{y}}{\text{댐퍼: 속도 억제}}$$

이것은 임계 감쇠 2차 시스템(critically-damped system)입니다:

항 물리적 의미 효과
$\alpha_y \beta_y (y_g - y)$ 스프링 — 현재 위치 $y$와 목표 $y_g$ 사이 거리에 비례하는 복원력 목표로 끌어당김
$-\alpha_y \dot{y}$ 댐퍼 — 속도에 비례하는 저항력 진동 없이 부드럽게 수렴

임계 감쇠 조건: $\alpha_y = 4\beta_y$일 때 오버슈트 없이 가장 빠르게 수렴

만약 $f(s) = 0$이면? → 그냥 직선으로 목표점에 수렴합니다 (재미없는 궤적).

f(s)=0일 때:

y값   y0 ●─────────────────● yg
          [시작]        [끝]
          → 단순 수렴, 직선적 이동

Part B: Shaping Force (식 3)

$$f(s) = h(s) \cdot (y_g - y_0) \cdot s$$

이것이 궤적의 "개성"을 만드는 핵심입니다:

구성요소 역할
$h(s)$ 학습 대상. "타이머가 $s$일 때 얼마나 밀 것인가" — 이 논문에서는 MLP가 학습
$(y_g - y_0)$ 공간 스케일링. 시작-끝 거리가 2배면 힘도 2배 → 궤적 형상이 비례적으로 유지
$s$ 시간 소멸 인자. $s \to 0$이면 $f \to 0$ → 목표점 수렴 보장

직관적 이해

f(s) 있을 때:

y값        ╭──╮
     y0 ●─╯    ╰──────● yg
         [시작]      [끝]
         → h(s)가 만드는 "곡선 경로"로 이동

shaping force가 하는 일: 스프링-댐퍼가 "목표로 직진!"이라고 할 때, shaping force가 "잠깐, 이쪽으로 돌아가!"라고 밀어줍니다. 그런데 $s$가 곱해져 있으므로, 동작 후반에는 밀어주는 힘이 자연스럽게 사라져서 결국 목표에 도달합니다.

3. 두 식의 협동 관계

시간 흐름 →→→

Canonical System:  s = 1.0 → 0.7 → 0.3 → 0.05 → ~0
                   ┃         ┃       ┃       ┃
                   ▼         ▼       ▼       ▼
Shaping Force:     강함      중간    약함    거의 0
                   ┃         ┃       ┃       ┃
                   ▼         ▼       ▼       ▼
궤적 특성:      형상 결정  형상유지  수렴시작  목표 도달
                (h가 지배)          (스프링 지배)
  1. 초반 ($s \approx 1$): shaping force가 강함 → $h(s)$가 정한 경로로 움직임
  2. 중반: shaping force와 스프링이 균형 → 궤적의 특징적 형상 유지
  3. 후반 ($s \approx 0$): shaping force 소멸 → 스프링-댐퍼가 지배 → 목표 수렴

4. 이 논문에서의 활용

이 논문에서는 전문가 굴삭기 운전자의 궤적을 DMP로 인코딩합니다:

  1. 전문가가 버킷을 움직인 경로 $(p_x(t), p_y(t))$를 기록
  2. 식 (2)를 역으로 풀어서 $f(s)$를 추출 → $h(s) = f(s) / ((y_g - y_0) \cdot s)$
  3. MLP가 $(s, T) \to h(s)$를 학습 (여기서 $T$는 경사/깊이 같은 지형 파라미터)
  4. 새 지형이 주어지면 → 학습된 $h(s)$로 전문가 스타일의 궤적을 생성

즉, 전문가의 "밀어주는 패턴" $h(s)$를 학습하면, 새로운 상황에서도 전문가처럼 움직일 수 있다는 것이 이 프레임워크의 핵심입니다.

더 깊이 들어가고 싶은 부분이 있으면 말씀해 주세요. 예를 들어: - Coupling Movement Primitives (온라인 변조 부분) - $h(s)$의 역추출 과정 (전문가 데이터에서 어떻게 뽑아내는지) - 공간 스케일링 $(y_g - y_0)$의 효과 (왜 이것이 일반화에 중요한지)

Q2. Canonical System의 수식 ($\tau \dot{s} = -\alpha_s s$)은 왜 이런 형태인가?

좋은 질문입니다! "왜 하필 이 식인가"부터 차근차근 풀어보겠습니다.

먼저, 우리가 원하는 것

DMP에서는 "동작이 지금 어디쯤 진행됐는지"를 알려주는 타이머가 필요합니다.

요구 조건은 딱 세 가지입니다:

# 조건 이유
1 시작할 때 값이 1 "동작 시작!" 신호
2 시간이 지나면 0으로 감소 "동작 끝!" 신호
3 한 번도 올라가지 않고 계속 내려감 (단조감소) 되돌아가면 안 되니까

가장 단순하게 이 세 조건을 만족하는 함수가 뭘까요?

제일 쉬운 시도: 그냥 직선?

$$s(t) = 1 - \frac{t}{T}$$

이것도 1에서 시작해서 0으로 가긴 하는데...

s   1.0 ╲
         ╲
          ╲
           ╲
    0.0     ╲____  ← T 이후에는? 음수가 됨! 💥

❌ 정확히 $T$ 시점에 맞춰 끝내야 하고, 그 이후에는 음수가 됩니다. 유연하지 않죠.

더 나은 시도: 지수 감소

자연에서 "서서히 줄어드는 것"의 가장 보편적인 패턴이 뭔가요?

"현재 남은 양에 비례해서 줄어든다"

예를 들어: - 뜨거운 커피가 식을 때 → 온도 차이에 비례해서 열이 빠짐 - 방사성 붕괴 → 남은 원자 수에 비례해서 붕괴 - 콘덴서 방전 → 남은 전하에 비례해서 방전

이걸 수식으로 쓰면:

$$\frac{ds}{dt} = -\alpha \cdot s$$

"$s$의 변화 속도($\dot{s}$)는, 현재 $s$ 값에 비례하여 감소한다"

이게 canonical system 식의 본질입니다.

식을 한 단계씩 조립

Step 1: 기본형

$$\dot{s} = -\alpha_s \cdot s$$

  • $\dot{s}$: $s$가 시간에 따라 얼마나 빨리 변하는가 (변화율)
  • $-$: 줄어드는 방향
  • $\alpha_s$: 얼마나 빨리 줄어드는가 (감쇠율, 양수)
  • $s$: 현재 남은 양에 비례

이 미분방정식을 풀면:

$$s(t) = e^{-\alpha_s t}$$

s   1.0 ●━━╲
            ╲
             ╲
              ╲━━━━━━━━━━  ← 절대 0 이하로 안 감!
    0.0 ─────────────────→ t

✅ 시작값 1, 단조감소, 절대 음수 안 됨, 부드러운 감소!

Step 2: 시간 스케일링 $\tau$ 추가

$$\tau \dot{s} = -\alpha_s \cdot s$$

이건 단순히 양변을 $\tau$로 나누면:

$$\dot{s} = -\frac{\alpha_s}{\tau} \cdot s$$

해는:

$$s(t) = e^{-\frac{\alpha_s}{\tau} t}$$

$\tau$가 하는 일은 전체 동작 속도를 조절하는 것입니다:

τ = 1 (빠름):    s   ●━╲
                        ╲━━━━━━━━

τ = 3 (느림):    s   ●━━━━━╲
                              ╲━━━━━━━━

$\tau$가 크면 → $s$가 천천히 줄어듦 → 동작이 느려짐 $\tau$가 작으면 → $s$가 빨리 줄어듦 → 동작이 빨라짐

💡 핵심: $\tau$를 바꾸면 궤적의 모양은 그대로 유지하면서 속도만 조절할 수 있습니다. 빨리 파든 천천히 파든 같은 형태의 삽질 동작!

왜 좌변이 $\tau \dot{s}$ 이고 $\dot{s}/\tau$가 아닌가?

논문에서 $\tau \dot{s} = -\alpha_s s$ 로 쓰는 이유는 DMP 동역학 식(식 2)과 형태를 통일하기 위해서입니다:

식 형태
Canonical: $\tau \dot{s} = -\alpha_s s$
DMP 동역학: $\tau \ddot{y} = \alpha_y(\beta_y(y_g - y) - \dot{y}) + f(s)$

양쪽 다 좌변에 $\tau$를 곱하는 형태로 통일해서, $\tau$ 하나만 바꾸면 시스템 전체가 동시에 같은 비율로 느려지거나 빨라지도록 설계한 것입니다.

핵심 정리

질문 답
이 식이 뭔가? "$s$가 자기 자신에 비례해서 줄어드는" 1차 미분방정식
왜 이 형태? 지수 감소 → 1에서 시작, 단조감소, 절대 음수 안 됨, 부드러움
$\alpha_s$는? 감쇠 속도 (클수록 빨리 0에 가까워짐)
$\tau$는? 전체 동작 속도 조절 다이얼 (DMP 동역학과 연동)
$s$의 역할은? shaping force $f(s) = h(s)(y_g - y_0) \cdot s$ 에서 $s \to 0$이면 $f \to 0$ → 목표 수렴 보장

이제 canonical system이 좀 감이 오시나요? 다음으로 동역학 식 (식 2) 의 스프링-댐퍼 부분을 같은 방식으로 풀어볼까요?

Q3. DMP 동역학 식의 스프링-댐퍼와 Shaping Force는 어떻게 작동하는가?

좋습니다! 이제 DMP 동역학 식 (식 2)으로 넘어갑니다.

DMP 동역학: 우리가 원하는 것

"시작점 $y_0$에서 출발해서 목표점 $y_g$에 도착하되, 가는 길은 우리가 원하는 형상으로"

이걸 만들려면 두 가지가 필요합니다:

역할 담당
목표에 반드시 도착하게 하는 힘 스프링-댐퍼
가는 길을 결정하는 힘 shaping force $f(s)$

Step 1: 스프링-댐퍼부터 이해하기

식 (2)에서 $f(s)$를 빼고 보면:

$$\tau \ddot{y} = \alpha_y(\beta_y(y_g - y) - \dot{y})$$

이걸 전개하면:

$$\tau \ddot{y} = \underbrace{\alpha_y \beta_y (y_g - y)}{\text{① 스프링}} - \underbrace{\alpha_y \dot{y}}{\text{② 댐퍼}}$$

① 스프링 항: $\alpha_y \beta_y (y_g - y)$

"목표에서 멀수록 세게 당긴다"

현재 위치 y          목표 yg
    ●───────────────→●
    ←── (yg - y) ──→
         이 거리에 비례하는 힘으로 당김
  • $(y_g - y)$가 크면 → 힘이 큼 → 빠르게 이동
  • $(y_g - y)$가 작으면 → 힘이 작음 → 천천히 접근
  • $y = y_g$이면 → 힘 = 0 → 딱 멈춤

② 댐퍼 항: $-\alpha_y \dot{y}$

"빨리 움직일수록 브레이크를 건다"

왜 필요한가? 스프링만 있으면 이렇게 됩니다:

스프링만 있을 때:
y ─────╱╲╱╲╱╲──── yg    ← 목표를 지나쳤다 돌아오고, 또 지나치고... 진동!

댐퍼를 추가하면:

스프링 + 댐퍼:
y ─────────╱─────── yg   ← 깔끔하게 수렴!

임계 감쇠 조건

$\alpha_y = 4\beta_y$로 설정하면 임계 감쇠(critically damped): - 진동 없이 (오버슈트 없이) - 가장 빠르게 수렴

🔑 이건 2차 미분방정식의 고전적 결과입니다. 문 닫힘 장치(도어클로저)가 바로 이 원리 — 쾅 닫히지도, 느리지도 않게 딱 맞게 닫히는 감쇠.

Step 2: 이것만으로는 부족한 이유

스프링-댐퍼만으로는 궤적이 항상 직선(혹은 단조증가 곡선)입니다:

스프링-댐퍼만:
         y0 ●━━━━━━━━━━━━━● yg
            직선적 이동만 가능

하지만 굴삭기의 버킷은 이런 경로를 따라야 합니다:

실제 굴착 궤적:
         y0 ●╲
               ╲        ← 땅 속으로 파고 들어감
                ╲___╱● yg
                     ↑ 퍼 올림

직선이 아닌 복잡한 형상이 필요 → 그래서 $f(s)$가 등장합니다.

Step 3: Shaping Force $f(s)$ 추가

$$\tau \ddot{y} = \alpha_y(\beta_y(y_g - y) - \dot{y}) + f(s)$$

$f(s)$는 "스프링-댐퍼가 만드는 직선 경로를 옆으로 밀어내는 외력"입니다.

$f(s)$의 구조 (식 3)

$$f(s) = \underbrace{h(s)}{\text{형상 함수}} \cdot \underbrace{(y_g - y_0)}{\text{공간 스케일링}} \cdot \underbrace{s}_{\text{소멸 인자}}$$

세 요소를 각각 보겠습니다:

ⓐ $h(s)$: "언제 얼마나 밀 것인가"

이것이 학습의 대상입니다. 전문가 굴착 궤적의 "개성"이 여기에 담깁니다.

h(s)의 예시:

       │    ╱  ╲          ← s=0.7 부근에서 강하게 위로 밀기
    0  │───╱────╲──────
       │          ╲       ← s=0.3 부근에서 아래로 밀기
   -1  │           ╲╱
       └──────────────→ s
       1              0
     [시작]         [끝]

ⓑ $(y_g - y_0)$: 공간 스케일링

"시작-끝 거리가 2배면, 미는 힘도 2배"

왜 필요한가? 같은 형상의 궤적을 크기만 다르게 재현하기 위해서입니다.

작은 동작:  y0●──╲╱──●yg        거리 = 2m, f도 작음
큰 동작:   y0●────╲╱────●yg     거리 = 4m, f도 2배 → 같은 형상 유지!

ⓒ $s$: 소멸 인자

이것이 목표 수렴을 보장하는 핵심 장치입니다.

아까 canonical system에서 $s$는 $1 \to 0$으로 감소한다고 했죠?

$$f(s) = h(s) \cdot (y_g - y_0) \cdot s$$

$s \to 0$이면 → $h(s)$가 아무리 커도 $f(s) \to 0$

동작 후반에는 shaping force가 자동으로 사라지고, 스프링-댐퍼만 남아서 목표에 수렴!

시간 흐름 →→→

              │           │           │           │

              │           │           │           │
지배하는 힘:  f(s)가 지배  균형        스프링 지배  스프링만
              │           │           │           │
궤적 특성:   형상 결정    형상 유지    수렴 시작    목표 도달 ✓

전체 식의 동작을 하나의 비유로

$$\tau \ddot{y} = \underbrace{\alpha_y(\beta_y(y_g - y) - \dot{y})}{\text{고무줄 + 브레이크}} + \underbrace{f(s)}{\text{가이드의 손}}$$

🎯 비유: 당신이 눈을 감고 목표 지점까지 걸어간다고 상상하세요.

  • 고무줄 (스프링): 목표 지점에 고무줄이 연결되어 있어서 계속 당겨짐
  • 진흙탕 (댐퍼): 발이 진흙에 빠져서 급가속이 안 됨 → 부드럽게 이동
  • 가이드 (shaping force): 옆에 서서 "여기서 오른쪽!", "여기서 아래로!" 하고 밀어줌
  • 가이드의 퇴장 ($s \to 0$): 목표 가까이 오면 가이드가 슬슬 손을 놓음 → 고무줄이 목표로 끌어당김

기본 DMP (식 2)를 1차 시스템 두 개로 쪼개서 쓰면:

Q5. "Canonical"이라는 용어의 의미는?

Canonical의 의미

Canonical은 수학/물리/공학에서 "표준적인", "기준이 되는", "가장 단순한 대표 형태"라는 뜻입니다.

일상적 비유

영어 한국어 대응 예시
canonical form 표준형 2차 방정식의 $ax^2 + bx + c = 0$
canonical example 대표적 예시 "Hello World"는 프로그래밍의 canonical example
canonical coordinates 정준 좌표 해밀턴 역학의 $(q, p)$

어원은 라틴어 "canon" (규칙, 기준)에서 왔습니다. 교회법(canon law)에서 "정경(正經)"이라는 뜻으로도 쓰이죠 — "이것이 공식적이고 기준이 되는 것"이라는 뉘앙스입니다.

DMP에서 "Canonical System"이라 부르는 이유

DMP에는 여러 개의 방정식이 동시에 돌아갑니다: - $p_x$ 방향의 DMP 동역학 - $p_y$ 방향의 DMP 동역학 - (필요하면 $\phi$ 방향도)

이 모든 것이 하나의 공통 시계 $s$를 공유합니다:

        Canonical System (공통 시계)
              τṡ = -αs·s
                  │
         s 값을 모두에게 전달
          ╱       │       ╲
         ▼        ▼        ▼
     DMP(px)   DMP(py)   DMP(ϕ)
     각자의     각자의     각자의
     동역학     동역학     동역학

"모든 축(차원)이 참조하는 유일한 기준 시스템" → 그래서 canonical(표준, 기준)이라 부릅니다.

만약 각 축마다 별도의 타이머를 쓰면, $p_x$는 70% 진행했는데 $p_y$는 30%만 진행하는 식으로 동기화가 깨집니다. Canonical system 하나로 통일하면 모든 축이 같은 진행도로 움직이게 되죠.

다음 궁금한 부분 있으시면 계속 진행합시다!

Q6. Shaping force $f(s)$는 궤적에 직교하는 힘이 아닌 해당 축 방향의 힘인가?

맞습니다! 좋은 지적입니다. 제가 "옆으로 밀어낸다"는 비유가 오해의 여지가 있었네요.

정확한 이해

$f(s)$는 $y$와 같은 축 방향으로 작용하는 힘입니다.

식 (2)를 다시 보면:

$$\tau \ddot{y} = \alpha_y(\beta_y(y_g - y) - \dot{y}) + f(s)$$

여기서 $\ddot{y}$와 $f(s)$는 같은 차원, 같은 방향입니다.

즉, $y$가 $p_x$이면 $f(s)$도 $x$축 방향의 힘이고, $y$가 $p_y$이면 $f(s)$도 $y$축 방향의 힘입니다.

그러면 곡선 궤적은 어떻게 만들어지나?

$p_x$와 $p_y$에 각각 독립적인 DMP가 돌아갑니다:

$$\tau \ddot{p}x = \alpha_y(\beta_y(p{gx} - p_x) - \dot{p}_x) + f_x(s)$$

$$\tau \ddot{p}y = \alpha_y(\beta_y(p{gy} - p_y) - \dot{p}_y) + f_y(s)$$

$f_x$와 $f_y$가 각자 자기 축 방향으로 "더 가" 또는 "덜 가"를 조절합니다:

              py
              ↑
              │        ● yg = (pgx, pgy)
              │       ╱
              │      ╱  ← 2D 합성 궤적 (곡선)
              │    ╱╱
              │  ╱╱
              │╱
     y0 ●─────┼──────────→ px
              │

px 축: f_x(s)가 "이 시점에서 x를 더 가" 또는 "덜 가" 조절
py 축: f_y(s)가 "이 시점에서 y를 더 가" 또는 "덜 가" 조절

→ 두 축의 합성 결과가 곡선이 됨

구체적 예시

시점 ($s$) $f_x$ $f_y$ 효과
초반 ($s=0.9$) 양수 (크게) 음수 (크게) x를 빨리 진행 + y를 아래로 → 아래로 깊이 파고듦
중반 ($s=0.5$) 양수 (작게) 0 x만 약간 진행 → 수평 이동
후반 ($s=0.2$) 0 양수 (크게) y를 위로 → 퍼올림

각 축의 $f$는 자기 축 방향으로만 "가속/감속"을 조절하는데, 두 축을 합치면 곡선 경로가 나오는 것입니다.

정리

$f(s)$는 직교 방향으로 미는 힘이 아니라, 해당 축 방향으로 "더 가라/덜 가라"를 조절하는 힘입니다.

2D 곡선 궤적은 $f_x(s)$와 $f_y(s)$가 각자 자기 축에서 독립적으로 조절한 결과의 합성으로 만들어집니다.

제 이전 비유가 부정확했습니다. 감사합니다!

Q7. $s$가 단조감소하므로 중간에 강한 힘이 필요한 응용에는 DMP를 사용할 수 없는가?

좋은 질문인데, 반은 맞고 반은 틀립니다!

$s$가 감소한다고 해서 $f(s)$도 반드시 감소하는 건 아닙니다

$f(s) = h(s) \cdot (y_g - y_0) \cdot s$에서 $s$는 줄어들지만, $h(s)$는 학습되는 자유 함수입니다.

중반에 큰 힘이 필요하면? $h(s)$를 크게 만들면 됩니다:

s=0.3 시점에서 f(s)=10을 원한다면?

  f(s) = h(s) · (yg-y0) · s
  10   = h(s) · 1 · 0.3
  h(s) = 33.3              ← h가 알아서 커지면 됨

실제 예시:

s:     1.0 ━━━╲
                ╲━━━━━━━━━━  0에 수렴
h(s):              ╱╲
       ━━━━━━━━╱    ╲━━━━   ← 중반에 확 커짐

f(s) = h·(yg-y0)·s:
                ╱╲
       ━━━━━━╱    ╲━━━━━━   ← 중반에 강한 힘 가능!

$h(s)$가 $s$의 감소를 보상할 수 있기 때문에, 중반에 강한 힘을 쓰는 것은 가능합니다.

그럼 진짜 한계는 뭔가?

맞는 부분은 궤적의 끝부분에 대한 것입니다:

$$s \to 0 \implies f(s) \to 0 \quad \text{(h가 아무리 커도)}$$

정확히 말하면, $s$가 0.01, 0.001 수준으로 작아지면 $h(s)$를 아무리 키워도 한계가 있고, 수치적으로도 불안정해집니다.

구간별 자유도:

   초반        중반         후반 끝부분
  s≈1.0      s≈0.3~0.5     s≈0.01~0
    │           │             │
    ▼           ▼             ▼
  자유롭게    h로 보상 가능   f→0 강제 (수렴 보장)
  형상 설계   여전히 자유도↑  ← 여기만 제약!

정리하면

구간 강한 힘 가능? 이유
초반 ($s \approx 1$) ✅ 자유 $s$가 크니까 $h$가 작아도 됨
중반 ($s \approx 0.3$~$0.5$) ✅ 가능 $h(s)$를 키워서 보상
끝부분 ($s \approx 0$) ❌ 불가 $s \cdot h$가 어쨌든 0으로 수렴

🔑 DMP의 진짜 제약은 "초반이 강하고 끝이 약하다"가 아니라, "궤적의 맨 끝에서는 반드시 외력이 사라지고 목표점에 수렴해야 한다"는 것입니다.

이건 단점이라기보다 의도된 설계입니다 — 목표 수렴 보장이 DMP의 핵심 장점이니까요. 굴삭기가 삽질 끝에 버킷을 정확한 위치로 가져가야 하는 것처럼, "끝은 반드시 목표점"이라는 보장이 산업 현장에서는 오히려 안전한 특성입니다.

Q8. 스프링-댐퍼의 초기 큰 힘도 $h(s)$로 조절 가능하며, DMP의 핵심 제약은 목표 수렴인가?

정확하게 핵심을 짚으셨습니다!

정리하면

스프링-댐퍼만 놓고 보면 이런 특성이 있습니다:

스프링력:  αyβy(yg - y)

  힘 크기
    │■■■■■■■■
    │■■■■■■
    │■■■■               ← (yg - y)가 줄어드니까 힘도 줄어듦
    │■■
    │■
    └──────────→ 시간
   [시작]     [끝]

그래서 "초반에 빠르고 끝에 느려지는" 경향이 기본적으로 있죠.

하지만 $h(s)$가 이걸 덮어쓸 수 있습니다:

스프링이 세게 당기는 초반에     h(s)가 반대 방향으로 밀어서
빠르게 가려는 것을      →     "천천히 가"로 바꿀 수 있고

스프링이 약해지는 중반에        h(s)가 같은 방향으로 밀어서
느려지려는 것을          →     "더 빨리 가"로 바꿀 수 있음

즉, $h(s)$는 스프링-댐퍼의 기본 거동을 자유롭게 왜곡하는 역할입니다.

그렇다면 스프링-댐퍼는 왜 필요한가?

$h(s)$가 다 해결하면 스프링-댐퍼 없이 $f(s)$만 있으면 되지 않나? 라는 의문이 들 수 있는데, 말씀하신 대로 $s \to 0$ 이후가 답입니다.

궤적 진행 중                    궤적 끝

f(s) 활성 구간                  f(s) ≈ 0 구간
├────────────────────────┤├──────────┤

h(s)가 자유롭게 형상 결정        스프링-댐퍼만 남음
                                → 목표점에 수렴 보장!

만약 스프링-댐퍼 없이 $f(s)$만 있으면:

상황 스프링-댐퍼 있을 때 스프링-댐퍼 없을 때
$f(s)$가 사라진 후 목표로 끌려감 ✅ 아무 힘도 없음 → 어디서 멈출지 모름 ❌
$h(s)$ 학습이 약간 부정확해도 스프링이 보정 오차가 그대로 누적 ❌

🔑 스프링-댐퍼 = 안전망입니다. $h(s)$가 궤적을 아무리 자유롭게 만들어도, 마지막에는 반드시 스프링-댐퍼가 목표점으로 데려다줍니다. 학습이 완벽하지 않아도 최소한 목표점에는 도달한다는 보장이죠.

이게 바로 이 논문에서 굴삭기처럼 안전이 중요한 산업 응용에 DMP를 선택한 이유이기도 합니다. 궤적이 좀 이상해져도 버킷은 결국 의도한 위치에 도달하니까요.

다음으로 넘어갈까요? Coupling Movement Primitives는 이미 설명드렸으니, 남은 주요 토픽은: - 모멘텀 기반 굴착력 추정 (식 6, 7) — 추가 센서 없이 힘을 어떻게 추정하는가 - $h(s)$ 역추출 + MLP 학습 과정 — 전문가 데이터에서 어떻게 배우는가

Q9. $h(s)$는 스칼라 값을 반환하는 함수인가?

네, 맞습니다. $h(s)$는 $s$ 값 하나를 받아서 실수 하나를 반환하는 함수입니다.

정확히 말하면

이 논문에서는 $h$가 $s$만이 아니라 Task Parameter $T$도 입력으로 받습니다:

$$h = \text{MLP}(s, T)$$

입력 의미 예시
$s$ 현재 동작 진행도 0.7 (30% 진행)
$T = (\theta_{\text{slope}}, d)$ 지형 조건 (20도 경사, 깊이 1.5m)
출력 의미
$h(s) \in \mathbb{R}$ 이 시점에서의 shaping 강도 (스칼라 하나)

동작 방식

매 제어 주기마다:

s = 0.7, T = (20°, 1.5m)  →  MLP  →  h = -2.3 (스칼라 하나)
                                          │
                                          ▼
                              f(s) = -2.3 × (yg-y0) × 0.7

$s$가 1에서 0으로 흘러가면서, MLP가 매 순간의 $h$ 값을 하나씩 뱉어주는 것입니다:

s=1.0  → h=0.5
s=0.9  → h=1.2
s=0.8  → h=2.8
s=0.7  → h=-2.3     ← 이런 식으로 s마다 다른 값
s=0.6  → h=-1.1
  ⋮        ⋮
s=0.0  → h=0.1      (하지만 f = h·(yg-y0)·0 = 0)

그래서 $p_x$와 $p_y$ 각각에 대해 별도의 MLP (또는 별도의 출력 노드)가 있어서, $h_x(s,T)$와 $h_y(s,T)$를 각각 반환합니다.

Q10. $\tau$와 $\alpha_s$는 하나로 합쳐도 되는데, 왜 분리하는가?

날카로운 지적입니다. 수학적으로는 맞아요:

$$\tau \dot{s} = -\alpha_s s \quad \Rightarrow \quad \dot{s} = -\frac{\alpha_s}{\tau} s$$

비율 $\frac{\alpha_s}{\tau}$만 의미 있으니까, 하나로 합쳐도 같은 해가 나옵니다.

그런데 왜 분리하는가?

핵심은 $\tau$가 이 식에만 쓰이는 게 아니라는 것입니다:

                    τ (공유!)
                 ╱     │      ╲
                ▼      ▼       ▼
           τṡ = -αs·s   τp̈x = αy(βy(…)-ṗx)+fx   τp̈y = αy(βy(…)-ṗy)+fy
           ~~~~~~~~~~~   ~~~~~~~~~~~~~~~~~~~~~~~   ~~~~~~~~~~~~~~~~~~~~~~~
           canonical      DMP (px)                  DMP (py)
파라미터 역할 영향 범위
$\tau$ 전체 동작 속도 모든 식에 공통
$\alpha_s$ canonical system의 감쇠율 canonical system만
$\alpha_y, \beta_y$ 스프링-댐퍼 특성 DMP 동역학만

구체적 예시

$\tau$만 2배로 바꾸면:

τ: 1 → 2

canonical:  τṡ = -αs·s     → s가 천천히 줄어듦
DMP(px):    τp̈x = ...      → px도 천천히 변화
DMP(py):    τp̈y = ...      → py도 천천히 변화

결과: 궤적 형상 동일, 속도만 절반 (동작 2배 느림)

모든 것이 동시에 같은 비율로 느려짐 → 형상 유지

만약 $\alpha_s$만 바꾸면:

αs: 1 → 2

canonical:  s가 더 빨리 줄어듦 → f(s)가 일찍 사라짐
DMP 동역학: αy, βy는 그대로 → 스프링-댐퍼 특성 불변

결과: shaping force가 일찍 소멸 → 궤적 후반이 더 빨리 "직선 수렴 모드"로 전환

합쳐버리면 생기는 문제

만약 $\gamma = \alpha_s / \tau$로 합치면:

canonical:  ṡ = -γ·s          ← γ 하나로 OK

그런데 DMP는?
  τp̈x = αy(βy(…) - ṗx) + fx  ← 여기 τ가 여전히 필요!

동작을 느리게/빠르게 하려면 결국 $\tau$가 별도로 필요합니다. 그런데 canonical system에서 $\tau$를 없애고 $\gamma$만 쓰면, 동작 속도를 바꿀 때 $\gamma$와 DMP의 $\tau$를 동시에 맞춰서 조정해야 하는 번거로움이 생깁니다.

분리해두면:

$\tau$만 바꾸면 전체가 자동으로 동기화 — 건드릴 곳이 한 군데뿐

한마디로

$\tau$는 시스템 전체의 공통 시간 다이얼이고, $\alpha_s$는 canonical system 고유의 감쇠 특성입니다. 역할이 다르기 때문에 분리해 놓아야 독립적으로 조절할 수 있습니다.

Q11. DMP에서 $y$는 위치 벡터의 각 성분(예: $p_x$, $p_y$)을 의미하는가?

네, 맞습니다!

DMP에서 $y$의 의미

DMP 식 하나는 스칼라(1차원) 하나를 담당합니다:

$$\tau \ddot{y} = \alpha_y(\beta_y(y_g - y) - \dot{y}) + f(s)$$

이 $y$가 위치의 각 성분 하나입니다.

이 논문의 경우 (2차원)

버킷 팁 위치가 $q = (p_x, p_y, \phi)$인데, DMP는 $p_x$, $p_y$에 각각 적용:

DMP $y$ $y_0$ $y_g$ $h(s)$
DMP 1 $p_x$ 시작 x좌표 목표 x좌표 $h_x(s, T)$
DMP 2 $p_y$ 시작 y좌표 목표 y좌표 $h_y(s, T)$ 
DMP 1:  τp̈x = αy(βy(pgx - px) - ṗx) + hx(s,T)·(pgx-p0x)·s
DMP 2:  τp̈y = αy(βy(pgy - py) - ṗy) + hy(s,T)·(pgy-p0y)·s
                                         ~~~~~~~~~~~~~~~~~~~
                                         각각 다른 h 함수!

($\phi$는 DMP가 아니라 기하학 알고리즘으로 별도 계산 — 노트의 3.6절)

3차원이라면?

로봇 팔처럼 $(x, y, z)$ 3차원 작업이면 DMP 3개:

DMP 담당
DMP 1 $x$ 좌표
DMP 2 $y$ 좌표
DMP 3 $z$ 좌표

각각 독립적인 $h(s)$를 갖되, canonical system ($s$)은 하나를 공유합니다:

              canonical system
              τṡ = -αs·s
                   │
            s를 공유 (동기화)
           ╱       │       ╲
          ▼        ▼        ▼
      DMP(x)    DMP(y)    DMP(z)
      hx(s)     hy(s)     hz(s)
       각자 독립된 shaping force

🔑 각 축이 독립적으로 "더 가/덜 가"를 조절하되, 진행도($s$)는 동기화 — 이것이 DMP가 다차원 궤적을 자연스럽게 생성하는 구조입니다.

Q12. DMP는 로봇 매니퓰레이터에서 많이 사용되는가? 기존 경로계획+제어 방식(A*, RRT, TO + PID, MPC)과 비교한 장점은?

좋은 질문입니다. DMP가 기존 경로계획+제어 방식과 어떻게 다른지 정리해 드리겠습니다.

먼저, 두 접근법의 패러다임 차이

DMP를 쓰는 핵심 이유 3가지

1. 모델링이 불가능하거나 너무 어려운 환경

기존 방식의 전제:
  "환경을 수학 모델로 표현할 수 있다"

  공장 로봇팔:  장애물 위치 정확히 알고, 동역학 모델 있음 → ✅ 가능
  굴삭기 굴착:  토양 역학? 매번 다른 지반? → ❌ 모델링 불가능

DMP의 장점

① 토양 모델이 필요 없다

TO+MPC:
  동역학 모델 필요 → 토양 모델? Modified FEE 사용 (근사치)
                      ↓
              실제 토양과 다르면? → 제약조건 위반 가능성

DMP:
  전문가가 이미 토양 특성을 "체감"하고 작업함
  → 그 패턴을 통째로 학습 → 토양 모델링 불필요

이것이 DMP 논문이 실기 검증까지 성공한 핵심 이유입니다. 실제 현장의 토양은 시뮬레이션 모델과 다르기 때문에, 모델 의존도가 낮은 DMP가 실기 적용에 유리했습니다.

③ 실기 검증 완료

DMP 논문은 38톤 실기에서 평지/경사면 검증까지 마쳤고, TO+MPC 논문은 시뮬레이션만 수행했습니다.

TO+MPC의 장점

① 물리적 제약조건을 명시적으로 보장

이것이 가장 결정적인 차이입니다:

DMP의 안전 전략:
  힘 측정 → 임계값 초과? → 궤적을 얕게 변조

  문제: 힘 "이외"의 제약은?
  - 실린더가 스트로크 끝까지 가면? → 고려 안 됨 ❌
  - 펌프 유량 초과하면?           → 고려 안 됨 ❌
  - 파워 한계 초과하면?           → 고려 안 됨 ❌

TO+MPC의 안전 전략:
  매 주기 최적화 시 제약조건으로 포함:
  ✅ 힘/토크 상하한
  ✅ 총 파워 상한
  ✅ 실린더 변위 상하한
  ✅ 펌프 유량 상한
  → 물리적으로 실행 불가능한 궤적은 원천 차단

② 최적성을 추구한다

DMP:   "전문가만큼 잘 하자"        → 전문가가 최적이 아니면 궤적도 비최적
TO+MPC: "수학적으로 최적을 찾자"   → 에너지 최소 + 굴착량 최대를 비용함수로 직접 최적화

TO+MPC는 에너지 비용과 굴착 체적을 명시적으로 최적화하므로, 이론적으로 전문가보다 더 효율적인 궤적을 생성할 수 있습니다.

  → 더 정교하고 다차원적인 대응

두 논문은 사실 같은 문제를 정반대 방향에서 접근한 것입니다:

  • TO+MPC: 모델링을 감수하고, 수학적 최적성과 안전 보장을 확보

이상적으로는 두 장점을 결합하는 것이 최선이겠죠 — 예를 들어 DMP로 공칭 궤적을 빠르게 생성하되, MPC로 제약조건 만족을 보장하는 하이브리드 방식. 실제로 최근 연구 트렌드가 그 방향으로 가고 있고, 같은 서울대에서 나온 2025년 후속 논문이 이 두 흐름을 어떻게 통합했는지도 볼 만할 것 같습니다.

Q14. 두 논문 모두 모멘텀 기반 외력 추정을 사용하는데, 토양 모델 필요성에 차이가 있는가?

좋은 지적입니다. 제가 앞서 비교에서 부정확한 부분이 있었습니다. 다시 정리하겠습니다.

먼저 사실 확인

2021 논문을 다시 보면, Modified FEE는 알고리즘이 아니라 시뮬레이션 환경입니다:

시뮬레이션 환경: "Modified LuGre friction (실린더 마찰) + Modified FEE (토양-버킷 상호작용)"

즉 FEE는 가상의 토양을 만들기 위한 시뮬레이터이고, 알고리즘 자체는 토양 모델을 모릅니다.

실제로 두 논문 모두 외란/외력을 같은 방식으로 추정합니다:

DMP (2020) 식 (7) TO+MPC (2021) 식 (11)
방법 모멘텀 기반 외란 관측기 모멘텀 기반 외란 추정기
원리 $\hat{\tau}_{ext} = K_0(p(t) - \int(\cdots)ds - p(0))$ $\hat{\Delta} = K_E(p - p(0) - \int(\cdots)d\tau)$
필요한 것 로봇 동역학 모델 ($M, C, g$) + 마찰 모델 로봇 동역학 모델 ($M, C, g$)
토양 모델 ❌ 불필요 ❌ 불필요

둘 다 토양 모델 없이, 로봇 동역학만으로 외력을 추정합니다.

그러면 진짜 차이는 어디에?

말씀하신 대로 외력 추정 측면에서는 동등합니다. 차이는 추정한 외력을 어떻게 사용하는가에 있습니다:

                     │
          ┌──────────┴──────────┐
          ▼                     ▼
     DMP (2020)            TO+MPC (2021)
          │                     │
  "임계값 넘었나?"         "동역학 모델에 보정값으로 투입"
          │                     │

   NO  → 그대로             최적 궤적 재계산

DMP: 외력을 단순 판정에 사용

TO+MPC: 외력을 동역학 보정에 사용

x_{k+1} = f_d(x_k, u_k, Δ̂_k)    ← 외란 추정값이 모델에 직접 들어감

MPC가 이 보정된 모델로 최적화:
  - 힘/토크 한계 만족하면서
  - 파워 한계 만족하면서
  - 실린더 변위 한계 만족하면서
  - 전역 궤적에 최대한 가깝게

외력의 크기와 방향 모두를 동역학에 반영해서, 모든 제약을 만족하는 최적 경로를 재계산합니다.

제가 한 말 실제
"DMP는 토양 모델이 필요 없다" ✅ 맞음, 하지만...
"TO+MPC는 토양 모델이 필요하다" ❌ 틀림 — 토양 모델 없이 동역학 모델 + 외란 추정으로 동작

둘 다 토양 모델은 불필요합니다. 정확한 차이는:

DMP TO+MPC
로봇 동역학 모델 ($M, C, g$) 외력 추정에만 사용 외력 추정 + 궤적 최적화 + MPC 전부에 사용

진짜 차이는 "토양 모델 유무"가 아니라, 로봇 동역학 모델에 대한 의존도입니다. TO+MPC는 궤적 최적화와 MPC 모두에 정확한 동역학이 필요하고, DMP는 궤적 생성 자체는 전문가 시범에서 왔기 때문에 동역학 모델 정확도에 덜 민감합니다.

End-to-End가 유리한 점

① 수동 설계가 필요 없다

DMP 논문에서 사람이 직접 설계한 것들:

- Task Parameter를 뭘로 할지? → (θ_slope, d)로 결정 [수동]
- 지형 특징을 어떻게 추출? → 헤비사이드 함수 + 가우시안 피팅 [수동]
- 버킷 각도는? → 기하학적 최소 충돌 알고리즘 [수동]
- 변조 방향은? → 지면 수직 방향 [수동]
- 힘 임계값은? → 전문가 데이터 분석 후 수동 설정 [수동]

이 모든 "사람의 판단"이 성능의 천장을 결정합니다. End-to-end는 이런 병목이 없습니다.

② 멀티모달 입력을 자연스럽게 처리

DMP: 숫자 2개 (경사각, 깊이)만 입력 → 돌멩이? 나무뿌리? 모름
End-to-End: 카메라 + LiDAR 통째로 입력 → 시각적 맥락 전부 활용 가능

③ 더 복잡한 행동 패턴 표현 가능

DMP는 점-대-점(point-to-point) 운동에 특화되어 있습니다. 하지만 실제 굴착은:

실제 전문가 굴착:
  파기 → 걸리면 흔들기 → 다시 파기 → 퍼올리기 → 턴 → 투하

DMP: 시작점 → 끝점의 단일 궤적만 표현 (중간에 전략 변경 불가)
End-to-End: 전체 시퀀스를 통째로 학습 가능

그런데도 DMP가 여전히 의미있는 이유

이 세 가지가 해결되면 end-to-end가 DMP를 대체할 수 있지만, 2026년 현재 아직 갈 길이 있습니다.

Q16. Coupling Movement Primitives의 변조항은 이 논문의 독자 제안인가?

Coupling Movement Primitives의 출처

이 논문의 독자 제안이 아닙니다. 기존 로보틱스 논문에서 가져온 기법입니다.

논문에서 명시적으로 두 선행 연구를 인용하고 있습니다:

원래 아이디어: 가속도 레벨에만 coupling [18]

[18] Gams, Ijspeert, Schaal, Lenarčič (2009) — "On-line learning and modulation of periodic movements with nonlinear dynamical systems," Autonomous Robots

이것이 최초의 coupling 개념 — DMP의 가속도 레벨에 외력을 직접 추가하는 방식.

하지만 이 방식은 오버슈트 문제가 있었습니다.

개선된 기법: 속도 + 가속도 레벨 동시 coupling [19]

[19] Gams, Nemec, Ijspeert, Ude (2014) — "Coupling movement primitives: Interaction with the environment and bimanual tasks," IEEE Transactions on Robotics

이것이 이 논문에서 실제로 사용한 기법입니다. 논문 원문에서도 명확히 밝히고 있습니다:

"the technique of coupling movement primitives is suggested to control the desired dynamics like a PD controller by adding a coupling term to both the acceleration-level and velocity-level DMP dynamics [19]. In this paper, we use this technique"

정리: 이 논문의 기여 범위

[18] Gams et al. 2009:  가속도 레벨에 coupling → 오버슈트 문제
         │
         ▼
[19] Gams et al. 2014:  속도+가속도 동시 coupling → 오버슈트 해결 ✅
         │
         ▼ (그대로 가져옴)
이 논문 (2020):  [19]의 기법을 "굴착력 피드백"에 적용
구분 기존 기법 [19] 이 논문의 적용
coupling 수식 구조 기존 그대로 사용 동일
변조력 $C$의 원천 환경 접촉력, 양손 협응 등 굴착력 초과분
변조 방향 일반적 지면 수직 방향 (식 13)
임계값 기반 on/off 없음 (항상 활성) $F_{xcv} > F_{th}$일 때만 활성 (식 12)

즉, Coupling MP라는 도구 자체는 기존 것이고, 이 논문의 기여는 그 도구를 "굴착력 임계값 기반 얕은 방향 변조"라는 구체적 전략으로 설계하여 굴삭기에 적용한 것입니다.

이건 로보틱스에서 흔한 패턴이기도 합니다 — DMP, Coupling MP 같은 범용 프레임워크가 있고, 각 응용 논문에서는 그 프레임워크를 특정 도메인에 맞게 커스터마이징하는 방식이죠.

Q17. 원래 DMP 수식에 변조항을 직접 넣으면 될 텐데, 왜 $z$를 도입하고 속도 레벨에도 변조항을 추가하는가?

핵심을 찌르는 질문입니다. 이걸 이해하려면 "가속도에만 힘을 넣으면 왜 오버슈트가 생기는가"를 먼저 봐야 합니다.

먼저, "그냥 원래 식에 넣으면 안 되나?"

원래 2차 DMP에 변조력을 바로 추가하면 (참고문헌 [18]의 방식):

$$\tau \ddot{y} = \alpha_y(\beta_y(y_g - y) - \dot{y}) + f(s) + C$$

이게 가장 직관적이죠. 그런데 이러면 오버슈트가 생깁니다.

왜 오버슈트가 생기나?

가속도 레벨에 힘 $C$를 넣는다는 것은 뉴턴 제2법칙 ($F = ma$) 입니다:

C > 0 구간 (힘 초과 감지):
━━━━━━━━━━━━━━━━━━━━━━
  C가 위쪽으로 미는 힘을 가함
  → y가 가속됨
  → y가 속도를 얻음 (ẏ 증가)
  → y가 위로 이동함

  여기까지는 OK ✅

C → 0 시점 (힘이 임계값 이하로 돌아옴):
━━━━━━━━━━━━━━━━━━━━━━
  미는 힘은 사라졌지만...
  이미 얻은 속도(ẏ)는 남아있음!
  → y가 관성으로 계속 이동 → 오버슈트 💥
  → 스프링-댐퍼가 끌어당겨서 되돌아옴
  → 진동 발생

시간 순서로 보면:

y 위치
  │          ╱╲          ← 오버슈트!
  │         ╱  ╲
  │  원래  ╱    ╲  돌아옴
  │  궤적 ╱      ╲╱─── 진동 후 수렴
  │━━━━━╱
  │    ↑
  │  C 적용 시작
  └──────────────────→ 시간

문제의 본질: 가속도에 힘을 넣으면, 그 힘이 속도로 적분됩니다. 힘을 빼도 속도는 즉시 사라지지 않아요.

z를 도입하는 이유

2차 식을 1차 두 개로 분리합니다:

$$\tau \dot{z} = \alpha_y(\beta_y(y_g - y) - z) + f(s) \tag{z의 동역학}$$

$$\tau \dot{y} = z \tag{y와 z의 관계}$$

coupling 없으면 $z = \tau \dot{y}$, 즉 z는 스케일된 속도입니다.

이제 핵심 — 두 식에 변조를 따로따로 넣습니다:

$$\tau \dot{z} = \alpha_y(\beta_y(y_g - y) - z) + f(s) + c_2 \dot{C} \tag{4}$$

$$\tau \dot{y} = z + c_1 C \tag{5}$$

식 (5)가 핵심: 속도 레벨에 $c_1 C$를 넣는 효과

식 (5)를 잘 보면:

$$\tau \dot{y} = z + c_1 C$$

이건 $y$의 속도를 $C$로 직접 오프셋하는 것입니다. 가속도를 거치지 않고요.

C > 0 구간:
━━━━━━━━━━
  τẏ = z + c₁C
          ~~~~
  y의 속도에 c₁C만큼 직접 더함
  → y가 즉시 이동 (가속 과정 없이!)

C → 0 시점:
━━━━━━━━━━
  τẏ = z + 0 = z

  C가 사라지는 순간, 추가된 속도도 즉시 사라짐!
  → 관성으로 계속 가는 것이 없음 → 오버슈트 없음 ✅

이것이 핵심 차이입니다:

가속도에만 $C$ (참고문헌 [18]) 속도에 $c_1C$ (Coupling MP)
$C$ 적용 시 힘 → 가속 → 속도 축적 속도를 직접 오프셋
$C$ 제거 시 축적된 속도 남음 → 오버슈트 오프셋 즉시 제거 → 깔끔한 복귀

그러면 식 (4)의 $c_2 \dot{C}$는 왜 필요?

속도 레벨의 $c_1 C$만으로 오버슈트는 해결되지만, $C$가 갑자기 변할 때 문제가 생깁니다:

c₁C만 있을 때, C가 갑자기 켜지면:

τẏ = z + c₁C
              ↑ 갑자기 0 → 큰 값

→ ẏ가 순간적으로 점프 → 궤적에 꺾임(jerk) 발생 💥

$c_2 \dot{C}$는 $C$의 변화율에 반응합니다:

C가 갑자기 커지면 → Ċ가 큼 → c₂Ċ가 z의 변화를 예비적으로 조절
C가 안정되면     → Ċ ≈ 0  → 이 항은 자연히 사라짐

즉, $c_2 \dot{C}$는 $C$의 급격한 변화를 부드럽게 만드는 역할입니다.

PD 제어기와의 대응

두 항을 합치면 PD 제어기와 같은 구조입니다:

변조항 위치 PD 대응 역할
$c_1 C$ 속도 식 (5) P (비례) $C$의 크기에 비례하여 위치 직접 변경
$c_2 \dot{C}$ 가속도 식 (4) D (미분) $C$의 변화율에 반응하여 전환을 부드럽게 
P만 있으면:  즉각 반응하지만 급격함 (꺾임)
D만 있으면:  부드럽지만 관성 누적 (오버슈트)
P + D:      즉각 반응 + 부드러운 전환 ✅

시각적 비교

[18] 가속도에만 C:
y   ─────╱╲──────      ← 오버슈트 + 진동
              ╲╱

c₁C만 (속도만):
y   ─────╱┐──────      ← 오버슈트 없지만 꺾임
          └

c₁C + c₂Ċ (Coupling MP):
y   ─────╱─────────    ← 오버슈트 없고 부드러움 ✅

한마디로

Q20. Canonical system의 $s$는 어떻게 계산되는가? 위치 기반인가 시간 기반인가?

좋은 질문입니다. $s$는 위치가 아닌 순수하게 시간으로 계산됩니다.

$s$의 계산 방식

Canonical system은 독립적인 ODE입니다:

$$\tau \dot{s} = -\alpha_s s$$

해: $s(t) = e^{-\alpha_s t / \tau}$

매 제어 주기(100Hz = 10ms마다)에 이 식을 적분하면 끝입니다:

t = 0.00s → s = 1.000
t = 0.01s → s = 0.998    ← 10ms 후
t = 0.02s → s = 0.996    ← 20ms 후
    ⋮
t = 4.00s → s = 0.135    ← 4초 후
    ⋮
t = 8.00s → s = 0.018    ← 8초 후 (거의 0)

버킷이 지금 어디에 있는지와 무관하게, $s$는 그냥 시간에 따라 혼자 감소합니다.

핵심: $s$와 $y$는 서로 모른다

┌─────────────────────┐
│ Canonical System     │     s(t) = e^(-αs/τ · t)
│ τṡ = -αs · s        │     ← 시간만으로 계산, 위치(y) 참조 안 함
└──────────┬──────────┘
           │ s 값을 일방적으로 전달
           ▼
┌─────────────────────────────────┐
│ DMP 동역학                       │
│ τÿ = αy(βy(yg-y) - ẏ) + h(s)·(yg-y0)·s │
│                                   │     ← y가 s에 영향 주지 않음
└─────────────────────────────────┘
$s$ → $y$ $y$ → $s$
영향 ✅ $s$가 $f(s)$를 통해 $y$를 조종 ❌ $y$가 $s$에 영향 없음

$s$는 일방적으로 시간표를 전달하는 독립적인 시계입니다.

$\tau$는 어떻게 설정하나?

$\tau$가 $s$의 감소 속도를 결정하므로, 결국 "전체 동작이 몇 초에 끝나는가"를 결정합니다.

이 논문에서는:

"800 steps with 100Hz during 8 second-interval, the average working time of expert data"

파라미터 값 결정 방법
$\tau$ 8초에 맞춰 설정 전문가 18세트의 평균 굴착 시간
$\alpha_s$ $s$가 8초 후 $\approx 0$이 되도록 $\tau$와 함께 조정 
전문가 데이터:
  1세트: 7.2초
  2세트: 8.5초
  3세트: 7.8초     →  평균 ≈ 8초  →  τ를 이에 맞게 설정
   ⋮
  18세트: 8.3초

이 설계의 의미

장점: 구현이 매우 단순합니다. 위치 피드백 없이 타이머만 돌리면 됩니다.

한계: 실제 상황에서 예상보다 빨리/느리게 진행되어도 $s$는 신경 쓰지 않습니다.

정상 상황:
  t=4s, s=0.14 → f(s) 약해짐 → "궤적 후반부"
  실제 버킷도 목표 근처 → OK ✅

비정상 상황 (토양이 너무 단단해서 버킷이 거의 안 움직임):
  t=4s, s=0.14 → f(s) 약해짐 → "궤적 후반부라고 생각"
  실제 버킷은 아직 초반 위치 → 괴리 발생 ⚠️

  → 하지만 스프링-댐퍼가 목표로 끌어당기므로,
    결국 목표에는 수렴 (궤적 형상은 달라질 수 있음)
  → Coupling MP가 과도한 힘을 감지하면 변조로 대응

이것이 DMP의 근본적 특성입니다. $s$는 "지금 동작의 몇 %"를 시간 기준으로만 판단합니다. 위치 기반이 아니라서, 실제 진행 상황과 괴리가 생길 수 있지만, 스프링-댐퍼의 수렴성과 Coupling MP의 힘 변조가 이를 보완합니다.

Q22. 굴삭기 동역학 식의 쿨롱 마찰과 점성 마찰은 어디서 발생하는가?

마찰의 물리적 위치

식 (6)의 마찰항을 다시 보면:

$$M(\theta)\ddot{\theta} + C(\theta, \dot{\theta})\dot{\theta} + g(\theta) + \underbrace{F_s \text{sgn}(\dot{\theta})}{\text{쿨롱 마찰}} + \underbrace{B\dot{\theta}}{\text{점성 마찰}} = \tau_u + \tau_{\text{ext}}$$

이 마찰은 주로 유압 실린더 내부에서 발생합니다.

유압 실린더의 구조

굴삭기의 각 관절(붐, 암, 버킷)은 유압 실린더로 구동됩니다:

유압 실린더 단면:

  유압 오일 →  ┃▓▓▓▓▓▓▓▓▓▓┃  ← 유압 오일
               ┃▓▓▓▓▓▓▓▓▓▓┃
  실린더 벽 →  ┃──────┨████┃  ← 피스톤
               ┃▓▓▓▓▓▓▓▓▓▓┃
               ┃▓▓▓▓▓▓▓▓▓▓┃
                      ↑
                    씰(seal)
                  피스톤과 실린더 벽 사이의
                  밀봉 부품 (O-링 등)

① 쿨롱 마찰: $F_s \text{sgn}(\dot{\theta})$

발생 위치: 피스톤 씰(seal)과 실린더 벽 사이의 접촉

피스톤이 움직일 때:

  → 이동 방향                  ← 이동 방향
  ┃───┨████▶┃                 ┃◀████┨───┃
       ↕ 씰 마찰                    ↕ 씰 마찰

  어느 방향이든 씰이 벽에 눌리며 마찰 발생
  힘 크기는 속도와 무관, 방향만 반대

특성: - 속도의 크기와 무관 — 느리게 움직이든 빠르게 움직이든 마찰력 동일 - 속도의 방향에만 반대 — $\text{sgn}(\dot{\theta})$가 이것을 표현 - 정지 상태에서 움직이기 시작할 때 가장 체감됨

$$F_s \text{sgn}(\dot{\theta}) = \begin{cases} +F_s & \dot{\theta} > 0 \ -F_s & \dot{\theta} < 0 \end{cases}$$

마찰력

관절별 마찰

$F_s \in \mathbb{R}^{3\times3}$, $B \in \mathbb{R}^{3\times3}$이 행렬인 이유는 3개 관절 각각에 별도의 유압 실린더가 있기 때문입니다:

                  ┌─── 붐 실린더 (Fs₁, B₁)
                  │
  캐빈 ─── 붐 ───┤─── 암 실린더 (Fs₂, B₂)
                  │
                  └─── 버킷 실린더 (Fs₃, B₃)

실제로는 대각 행렬 (각 실린더가 독립):

$$F_s = \begin{bmatrix} F_{s,boom} & 0 & 0 \ 0 & F_{s,arm} & 0 \ 0 & 0 & F_{s,bucket} \end{bmatrix}$$

각 실린더마다 크기가 다르고, 씰 상태도 다르므로 마찰 계수가 각각 다릅니다.

부가적 마찰 원천

유압 실린더 외에 핀 조인트(pin joint)에서도 마찰이 발생합니다:

        붐
       ╱
  ────●──── 암       ← 이 ● 부분이 핀 조인트
      ↑                   대형 핀 + 부싱(bushing)
   핀 조인트 마찰           여기서도 쿨롱 마찰 발생

하지만 유압 실린더의 씰 마찰이 지배적이라, 논문에서는 이들을 통합하여 $F_s$, $B$로 모델링한 것입니다.

이 마찰 파라미터는 어떻게 구하나?

논문 원문에서:

"all the other terms can be identified via off-line parameter optimization"

즉, 실제 굴삭기를 무부하 상태에서 움직이며 ($\tau_{ext} = 0$), 측정된 운동 데이터로부터 $F_s$, $B$ 등을 오프라인 파라미터 최적화로 식별합니다. 이것이 앞서 말한 "로봇 동역학 모델"의 일부입니다.

Q23. 모멘텀 기반 외란 관측기의 수식은 어떻게 유도되는가?

굴삭기 동역학(식 6)에서 출발하여 관측기(식 7)를 처음부터 유도하겠습니다.

출발점: 동역학 식 (6)

$$M(\theta)\ddot{\theta} + C(\theta, \dot{\theta})\dot{\theta} + g(\theta) + F_s \text{sgn}(\dot{\theta}) + B\dot{\theta} = \tau_u + \tau_{\text{ext}}$$

우리의 목표: $\tau_{\text{ext}}$ (굴착 토크)를 추정하고 싶다.

가장 직관적인 방법은 식을 $\tau_{\text{ext}}$에 대해 정리하는 것:

$$\tau_{\text{ext}} = M\ddot{\theta} + C\dot{\theta} + g + F_s\text{sgn}(\dot{\theta}) + B\dot{\theta} - \tau_u$$

문제: $\ddot{\theta}$ (관절 가속도)가 필요한데, 이것은 IMU 신호를 미분해야 합니다. 미분은 노이즈를 증폭시켜 실용적이지 않습니다.

θ 측정값 (IMU):  ~~~~∿∿∿~~~~  약간의 노이즈
θ̇ (1차 미분):    ∿∿∿∿∿∿∿∿∿∿  노이즈 증폭
θ̈ (2차 미분):    ⚡⚡⚡⚡⚡⚡⚡⚡⚡⚡  노이즈 폭발! ❌

핵심 아이디어: 미분 대신 적분을 사용하면 노이즈가 줄어든다. 그래서 모멘텀(적분량)을 활용한다.

Step 1: 일반화 모멘텀 정의

$$p(t) = M(\theta)\dot{\theta}$$

$p$의 시간 미분을 구하면:

$$\dot{p} = \dot{M}\dot{\theta} + M\ddot{\theta}$$

여기서 $M\ddot{\theta}$를 동역학 식에서 대입합니다:

$$M\ddot{\theta} = \tau_u + \tau_{\text{ext}} - C\dot{\theta} - g - F_s\text{sgn}(\dot{\theta}) - B\dot{\theta}$$

따라서:

$$\dot{p} = \dot{M}\dot{\theta} + \tau_u + \tau_{\text{ext}} - C\dot{\theta} - g - F_s\text{sgn}(\dot{\theta}) - B\dot{\theta}$$

Step 2: 오일러-라그랑주 동역학의 핵심 성질 활용

로봇 동역학에는 잘 알려진 성질이 있습니다:

$$\dot{M} = C + C^T$$

($\dot{M} - 2C$가 반대칭(skew-symmetric) 행렬이라는 성질에서 유도됨)

이것을 대입하면:

$$\dot{p} = (C + C^T)\dot{\theta} + \tau_u + \tau_{\text{ext}} - C\dot{\theta} - g - F_s\text{sgn}(\dot{\theta}) - B\dot{\theta}$$

$C\dot{\theta}$가 상쇄됩니다:

$$\dot{p} = C^T\dot{\theta} + \tau_u + \tau_{\text{ext}} - g - F_s\text{sgn}(\dot{\theta}) - B\dot{\theta}$$

논문의 표기법으로 정리하면:

$$\boxed{\dot{p} = \tau_u + \tau_{\text{ext}} - \beta - \tau_\mu}$$

여기서: - $\beta = g(\theta) - C^T(\theta, \dot{\theta})\dot{\theta}$ - $\tau_\mu = F_s\text{sgn}(\dot{\theta}) + B\dot{\theta}$

✅ 이 식에는 $\ddot{\theta}$가 없습니다! $\dot{M} = C + C^T$ 성질 덕분에 깔끔하게 소거되었습니다.

Step 3: 양변을 적분

$$p(t) - p(0) = \int_0^t (\tau_u + \tau_{\text{ext}} - \beta - \tau_\mu) \, d\sigma$$

정리하면:

$$\tau_{\text{ext}} = \frac{d}{dt}\left[ p(t) - p(0) - \int_0^t (\tau_u - \beta - \tau_\mu) \, d\sigma \right]$$

아직 미분이 남아있네요. 여기서 관측기 구조를 도입합니다.

Step 4: 관측기 설계

보조 변수 $r(t)$를 정의합니다 — 이것은 "추정된 $\tau_{\text{ext}}$를 사용하여 계산한 모멘텀":

$$r(t) = \int_0^t (\tau_u - \tau_\mu - \beta + \hat{\tau}_{\text{ext}}) \, d\sigma + p(0)$$

실제 모멘텀 $p(t)$와 비교하면:

$$p(t) = \int_0^t (\tau_u - \tau_\mu - \beta + \tau_{\text{ext}}) \, d\sigma + p(0)$$

두 식의 차이:

$$p(t) - r(t) = \int_0^t (\tau_{\text{ext}} - \hat{\tau}_{\text{ext}}) \, d\sigma$$

$p(t) - r(t)$는 추정 오차의 적분입니다. 이 값이 크면 추정이 틀린 것.

이제 관측기를 다음과 같이 정의합니다:

$$\boxed{\hat{\tau}_{\text{ext}} = K_0 (p(t) - r(t))}$$

풀어쓰면:

$$\hat{\tau}{\text{ext}} = K_0 \left( p(t) - \int_0^t (\tau_u - \tau\mu - \beta + \hat{\tau}_{\text{ext}}) \, d\sigma - p(0) \right)$$

이것이 바로 논문의 식 (7)입니다.

Step 5: 왜 이것이 작동하는가? — 오차 동역학

추정 오차를 $e = \tau_{\text{ext}} - \hat{\tau}_{\text{ext}}$로 정의하면:

$$p(t) - r(t) = \int_0^t e \, d\sigma$$

관측기 정의에서:

$$\hat{\tau}_{\text{ext}} = K_0 \int_0^t e \, d\sigma$$

양변을 시간 미분하면:

$$\dot{\hat{\tau}}{\text{ext}} = K_0 \cdot e = K_0 (\tau{\text{ext}} - \hat{\tau}_{\text{ext}})$$

정리하면:

$$\boxed{\dot{\hat{\tau}}{\text{ext}} + K_0 \hat{\tau}{\text{ext}} = K_0 \tau_{\text{ext}}}$$

이것은 1차 저역통과 필터(low-pass filter)입니다!

입력: τ_ext (실제 굴착 토크)
          │
          ▼
    ┌─────────────┐
    │  K₀/(s+K₀)  │    ← 1차 저역통과 필터
    └──────┬──────┘
           │
           ▼
출력: τ̂_ext (추정된 굴착 토크)

Step 6: $K_0$의 역할

$$\text{전달함수}: \frac{\hat{\tau}{\text{ext}}(s)}{\tau{\text{ext}}(s)} = \frac{K_0}{s + K_0}$$

$K_0$ 시정수 $1/K_0$ 특성
크게 짧음 빠르게 추종, 하지만 노이즈에 민감
작게 길음 느리게 추종, 하지만 노이즈에 강함 
실제 τ_ext:    ──────╱╲──────────

K₀ 큼:        ──────╱╲──────────  ← 거의 즉시 따라감 (노이즈도 따라감)

K₀ 작음:      ────────╱─╲────────  ← 부드럽지만 지연됨

$K_0$는 추종 속도 vs 노이즈 억제의 트레이드오프를 조절합니다.

전체 유도를 한눈에

동역학: Mθ̈ + Cθ̇ + g + τμ = τu + τext
              │
              ▼ p = Mθ̇ 정의

모멘텀 미분: ṗ = Ṁθ̇ + Mθ̈
              │
              ▼ Ṁ = C + Cᵀ 성질 적용 → θ̈ 소거!

핵심 관계: ṗ = τu + τext - β - τμ
              │
              ▼ 양변 적분 (미분 회피!)

적분 관계: p(t) - p(0) = ∫(τu + τext - β - τμ)dt
              │
              ▼ 관측기: τ̂ext = K₀(p(t) - r(t))

오차 동역학: τ̂̇ext = K₀(τext - τ̂ext)
              │

$$f(s) = h(s) \cdot (y_g - y_0) \cdot s$$

$h(s)$를 학습하려면, 전문가 궤적에서 역으로 추출해야 합니다:

$$h(s) = \frac{f(s)}{(y_g - y_0) \cdot s}$$

만약 $y_g$가 궤적마다 다르면:

궤적 A: yg_A = (10, 0),   y0_A = (4, 2)  → (yg-y0)_A = (6, -2)

같은 형상의 궤적이라도 (yg-y0)가 다르면 → 추출된 h(s)도 달라짐
→ "궤적 형상"이 아닌 "스케일 차이"까지 h(s)가 학습해야 함
→ 학습 부담 증가, 일반화 성능 저하

$y_g$를 통일하면:

모든 궤적: yg = pg (동일)

궤적 A: (yg-y0)_A = (pg - y0_A)  → h_A(s) 추출
궤적 B: (yg-y0)_B = (pg - y0_B)  → h_B(s) 추출

이제 h(s)의 차이는 순수하게 "궤적 형상"과 "지형 조건(T)"의 차이만 반영
→ MLP가 (s, T) → h(s) 매핑을 깔끔하게 학습 가능

Q25. 위치 RMS 오차 0.51m은 무엇을 비교한 값인가?

위치 RMS 오차의 의미

논문 원문을 보면:

"For each time-stamp, the RMS (root mean square) error for the position yields 0.51m, and the dominant reason for the error is that the initial position has an error of 0.42m."

이것은 학습된 MLP로 재생성한 궤적과 원본 전문가 궤적을 비교한 오차입니다.

구체적으로 무엇을 비교했나?

전문가 원본 궤적:  y0_expert ●━━━╲━━━━━━● yg_expert
                              ╲━━━╱

MLP 재생성 궤적:   y0_DMP ●━━━╲━━━━━━● pg (공통 목표)
                              ╲━━╱

오차 = 매 시간 스텝마다 두 궤적 사이의 거리

$$\text{RMS} = \sqrt{\frac{1}{N}\sum_{k=1}^{N} |y_{\text{expert}}(t_k) - y_{\text{DMP}}(t_k)|^2} = 0.51\text{m}$$

왜 0.42m이 초기점 오차인가?

공간 스케일링 정규화에서 목표점은 $p_g$로 통일했지만, 시작점 $y_0$는 각 궤적마다 그대로 남아있습니다:

전문가 궤적의 실제 시작점:   y0_expert = (8.5, -0.3)
DMP가 사용하는 시작점:      y0_DMP = (8.1, 0.1)   ← 약간 다름

                            이 차이 ≈ 0.42m

이 초기 오프셋이 궤적 전체에 걸쳐 누적되기 때문에, 전체 RMS 0.51m 중 0.42m이 단순히 시작점 차이에서 비롯됩니다.

순수한 "궤적 형상" 오차만 보면:

$$\sqrt{0.51^2 - 0.42^2} \approx 0.29\text{m}$$

38톤 굴삭기의 작업 반경(약 10m)에 비하면 약 3% 수준으로, 형상 자체는 잘 학습된 것입니다.

Q26. DMP/변조는 버킷 팁 위치만 생성하고, 버킷 각도는 별도 계산하는 구조인가?

DMP + MLP가 생성하는 것: 버킷 팁의 위치 (pₓ, p_y)의 시간 궤적만 생성한다. Coupling Movement Primitives에 의한 온라인 변조도 이 (pₓ, p_y)에 대해서만 적용된다.

"버킷을 감싸는 가상 삼각형이 지면과 충돌하지 않는 최소 각도"

이다 (Section 3.6, Fig. 7).

  1. DMP + MLP → (pₓ(t), p_y(t)) 공칭 궤적 생성
  2. Coupling MP + 굴착력 피드백 → (pₓ(t), p_y(t)) 온라인 변조

DMP/변조 단계에서는 버킷이 어떤 자세인지 신경 쓰지 않고 "어디로 가는가"만 결정하고, 버킷 자세는 그 경로가 결정된 후 기하학적 조건으로 따로 풀어내는 구조이다.

Q29. DMP 궤적 생성은 글로벌 사전 계획이 아닌 로컬 온라인 생성 방식인가?

네, 이해가 정확합니다. 다만 약간의 뉘앙스를 추가하면:

DMP는 본질적으로 미분방정식 시스템

DMP의 궤적 생성은 매 타임스텝마다 다음 순서로 순차적으로 적분하는 방식입니다:

  1. 정규 시스템(eq.1)에서 현재 $s$ 값 업데이트: $\tau\dot{s} = -\alpha_s s$
  2. 현재 $(s, T)$ → MLP → $h(s)$ 계산
  3. $f(s) = h(s)(y_g - y_0)s$ 로 shaping force 산출
  4. DMP 동역학(eq.2)에 대입하여 $\ddot{y}$ 계산 → 적분으로 다음 $(\dot{y}, y)$ 획득

즉, 2차 ODE를 forward integration하는 것이므로 "로컬하게 다음 포인트를 생성"하는 것이 맞습니다.

단, 공칭 궤적 vs 실제 실행 궤적의 구분

  • 공칭(nominal) 궤적만 놓고 보면: $s$와 $T$는 실행 전에 이미 알 수 있으므로, 이론적으로는 ODE를 미리 다 적분해서 글로벌한 궤적을 사전에 생성하는 것도 가능합니다.
  • 그러나 Coupling Movement Primitives(eq.10-11)가 핵심: 변조력 $C(s)$는 실시간 굴착력 측정값 $F_{xcv}$에 의존합니다. 이 값은 실제로 굴착하면서만 알 수 있으므로, 사전 계산이 원천적으로 불가능합니다.

따라서 이 논문의 프레임워크는:

매 타임스텝마다 (현재 상태 $y, \dot{y}$) + (현재 $s$) + (지형 $T$) + (실시간 굴착력 $F_{xcv}$) → DMP+Coupling 동역학으로 다음 위치 산출 → 관절 제어로 이동 → 다시 다음 포인트 생성

이런 온라인 반응형(reactive) 궤적 생성 + 동시 제어 루프입니다. 글로벌 궤적을 먼저 만들고 추종하는 방식이 아닙니다.

이것이 바로 DMP의 큰 장점 중 하나인데, 궤적을 "동역학 시스템"으로 표현했기 때문에 외부 입력(coupling force)을 자연스럽게 주입할 수 있고, 그러면서도 목표점 수렴($s \to 0$)이 구조적으로 보장됩니다.

핵심은 버킷 치아가 진행 방향과 최대한 일치할수록 굴착 효율이 높다는 점입니다.

  • 이상적 상태: 버킷 치아가 속도 벡터 방향을 정확히 가리킴 → 토양을 가장 효과적으로 절삭
  • 문제: 이 상태에서는 버킷 몸체가 지면과 충돌
  • 타협점: 충돌을 겨우 피하는 최소 각도 → 절삭 효율 최대화

삽으로 비유하면: - 삽날을 땅과 거의 평행하게 밀면 → 잘 파짐 (작은 각도) - 삽날을 많이 세워서 밀면 → 긁기만 하고 잘 안 파짐 (큰 각도)

$\phi$가 필요 이상으로 크면: 1. 치아가 진행 방향에서 벗어나 절삭력이 분산됨 2. 토양을 자르기보다 밀어내는 비효율적 동작이 됨 3. 결과적으로 같은 깊이를 굴착하는 데 더 큰 힘이 필요하거나, 굴착량이 줄어듦

따라서 "충돌 안 하면 됐지"가 아니라, 굴착 생산성을 최대화하기 위해 충돌 회피를 만족하는 범위 내에서 가장 작은 각도를 선택하는 것입니다.

Q31. 전문가 힘 패턴 분석 상세 설명

굴착력 정규화

$$F_{xcv} = \sqrt{F_x^2 + F_z^2} \;/\; k$$

버킷 팁에 작용하는 수평($F_x$) + 수직($F_z$) 합력의 크기를 상수 $k$로 나눠 무차원화한 값입니다. 이렇게 하면 지형/조건에 관계없이 힘의 크기를 비교할 수 있습니다.

전문가의 사다리꼴(Trapezoid) 패턴

전문가 운전자의 $F_{xcv}$를 시간(또는 $s$)에 따라 그려보면 사다리꼴 형태가 나타납니다:

F_xcv
  │      ┌──────────────┐
  │     /│              │\
  │    / │  일정 유지    │ \
  │   /  │              │  \
  │  /   │              │   \
  ──┴────┴──────────────┴────┴── s (시간)
  진입    굴착 구간        이탈

이것이 의미하는 바: - 진입: 버킷이 토양에 진입하며 힘이 점진적으로 증가 - 굴착 구간: 힘을 일정 수준으로 유지 (과도하지도, 부족하지도 않게) - 이탈: 토양에서 빠져나오며 힘 감소

전문가가 사다리꼴 패턴을 쓰는 이유

숙련 운전자는 경험적으로 힘의 상한선을 체감하고 있습니다: - 힘이 너무 크면 → 장비에 무리, 전복 위험, 버킷 손상 - 힘이 너무 작으면 → 굴착량 부족, 생산성 저하 - 따라서 적정 범위 내에서 최대한 일정하게 유지하는 것이 최적 전략

평지 vs 경사면의 차이

평균 $F_{xcv}$ 표준편차 해석
평지 1.62 0.24 높은 힘, 낮은 분산 → 안정적 굴착
경사면 0.86 0.43 낮은 힘, 높은 분산 → 불안정, 조심스러운 굴착
  • 평지: 토양 저항이 예측 가능 → 전문가가 자신 있게 높은 힘으로 굴착
  • 경사면: 토양이 무너지거나 예측 불가 → 전문가도 힘을 줄이고 조심스럽게 운용, 변동도 큼

이 분석이 시스템 설계에 미치는 영향

이 패턴 분석에서 힘 임계값(threshold)을 도출합니다:

  • $F_{\text{th,flat}} = 1.5 \times 10^5$ N (평지)
  • $F_{\text{th,slope}} = 1.0 \times 10^5$ N (경사면)

이 임계값이 Coupling MP의 변조 트리거 역할을 합니다:

실시간 F_xcv 측정
     │
     ▼
F_xcv > F_threshold? ──No──→ 변조 없음 (공칭 궤적 유지)
     │
    Yes
     │
     ▼
C(s) = F_xcv - F_threshold → 궤적을 얕은 방향으로 밀어냄

즉 전문가가 "이 이상의 힘은 위험하다"고 판단하는 수준을 데이터에서 추출하고, 자율 시스템이 그 수준을 넘으면 자동으로 궤적을 수정하는 것입니다. 결과적으로 변조된 궤적의 힘 패턴도 전문가와 유사한 사다리꼴 형태가 되는 것이 실험(Figure 13)에서 확인되었습니다.

Q32. 각 하이퍼파라미터는 어떻게 결정했는가?

논문 요약에 명시적인 튜닝 방법론이 상세히 기술되어 있지는 않지만, 각 하이퍼파라미터의 성격에 따라 결정 방식을 추론할 수 있습니다.

DMP 기본 게인 (αy, βy) — 이론적 설정

DMP 문헌의 표준 관례에 따라 임계 감쇠(critical damping) 조건으로 설정합니다:

αy = 4βy

이렇게 하면 진동 없이 목표점에 부드럽게 수렴합니다. 사실상 튜닝이 필요 없는 파라미터입니다.

시간 스케일링 (τ), 감쇠율 (αs) — 데이터에서 결정

  • τ: 전문가 굴착 시간(평균 8초)에 맞춰 설정
  • αs: 궤적 종료 시점에 s ≈ 0이 되도록 역산
  • 데이터 정규화 과정(800 스텝, 100Hz)에서 자연스럽게 결정됨

MLP 구조 (64-16) — 경험적 선택

  • 너무 크면 → 18세트 소량 데이터에 과적합
  • 너무 작으면 → 지형 변화에 따른 h(s) 변화를 표현 못함
  • 논문에서 "강건하고 실무에서 잘 동작하는 기법 선택"이라 언급 → 실험적으로 적절한 크기를 찾은 것으로 보임

힘 임계값 (F_threshold) — 전문가 데이터에서 도출

이것은 가장 근거가 명확한 파라미터입니다:

지형 전문가 평균 전문가 표준편차 설정된 임계값
평지 1.62 0.24 1.5 × 10⁵ N
경사면 0.86 0.43 1.0 × 10⁵ N

전문가가 유지하는 힘의 상한 부근을 임계값으로 설정 — "전문가가 이 이상은 안 쓴다"는 수준을 데이터 통계에서 추출한 것입니다.

Coupling 게인 (αp, βp, c₁, c₂) — 수동 튜닝

이 부분이 가장 문제적인데, 논문이 한계점으로 직접 인정하고 있습니다:

"최적 coupling gain: c₁, c₂를 수동으로 설정 → 시스템에 맞는 최적 게인 자동 탐색 알고리즘 개발 필요"

  • αp = 5.0, βp = √20: 변조 동역학의 감쇠 특성 결정
  • c₁ = 0.03, c₂ = 0.008: 변조력이 궤적에 미치는 영향의 크기 결정

이들은 실기 시험에서 trial-and-error로 조정했을 가능성이 높습니다: - c₁, c₂가 너무 크면 → 과도한 변조, 굴착 자체가 안 됨 - 너무 작으면 → 변조 효과 미미, 과도한 힘 방지 실패

정리

파라미터 결정 방식 근거 수준
αy, βy 이론적 (임계감쇠) 확립된 이론
τ, αs 데이터 기반 명확
MLP 구조 경험적 보통
F_threshold 전문가 데이터 통계 명확
c₁, c₂, αp, βp 수동 튜닝 논문이 인정한 한계

결국 이 프레임워크에서 가장 설계자 의존적인 부분이 coupling 게인이고, 이것의 자동화가 향후 과제로 남아있는 상태입니다.

Q33. 공간 스케일링 정규화 수식의 상세 설명 (보충)

왜 필요한가?

DMP의 shaping force 수식 (3)에서:

f(s) = h(s) · (yg - y₀) · s

(yg - y₀)가 공간 스케일링 항이다. 이 항 덕분에 DMP는 시작점과 목표점 사이의 거리가 달라져도 궤적의 질적 형상(shape)을 보존할 수 있다.

그런데 전문가 18세트의 데이터는 각각 시작점 y₀과 목표점 yg가 다르다: - 평지 vs 경사면에서 굴착 시작/종료 위치가 다르고 - 같은 지형에서도 연속 굴착 시 점점 깊어지므로 위치가 달라짐

만약 각 데이터의 (yg - y₀)가 제각각이면, 같은 h(s) 함수를 학습해도 f(s)의 크기가 데이터마다 달라져서 일관된 학습이 어렵다.

수식 (9) 분해

$$\min_{p_g, p_r} \sum_{i=1}^{n} \left| |p_{o}^{(i)} - p_g| - p_r \right| \quad \text{s.t.} \quad x_l \le p_{gx} \le x_u, \quad y_l \le p_{gy} \le y_u$$

기호 의미
pg = (pgx, pgy) 찾고자 하는 공통 목표점 (모든 궤적이 공유)
po⁽ⁱ⁾ i번째 궤적의 실제 시작점 (초기점)
pr 공통 거리 (모든 초기점에서 pg까지의 이상적 거리)
n 학습 궤적 수 (= 18)
xl, xu, yl, yu pg의 탐색 범위 (물리적으로 합리적인 영역 제한)

직관적 해석

핵심: "pg를 찾되, 모든 초기점 po⁽ⁱ⁾에서 pg까지의 거리가 가능한 한 동일한 값 pr이 되게 하라"

기하학적으로는 pg를 중심으로 반지름 pr인 원을 그렸을 때, 모든 초기점이 이 원 위에 최대한 가깝게 놓이는 pg와 pr을 찾는 것이다.

DMP에서의 효과 흐름

각 궤적마다 다른 (y₀, yg)
        ↓
최적화로 공통 pg, pr 산출 (수식 9)
        ↓
모든 궤적의 목표점을 pg로 통일
        ↓
(yg - y₀) ≈ pr 로 공간 스케일링 동일화
        ↓
h(s) = f(s) / ((yg-y₀)·s) 가 궤적 간 비교 가능
        ↓
MLP가 (s, T) → h(s) 를 일관되게 학습

이 정규화의 목적은, 궤적의 형상 차이가 오직 지형 조건(경사, 깊이)에만 기인하도록 스케일 차이를 제거하는 것이다.

Q34. pg, pr은 시작점만으로 결정되는데 실제 끝점에 도달 못하는 문제는?

pg와 pr은 수식 (9)에서 초기점 po⁽ⁱ⁾들만 사용하여 결정되고, 각 궤적의 실제 끝점 yg⁽ⁱ⁾,actual은 제각각이다. 실제 궤적이 pg에 도달하지 못할 수 있지 않은가?

DMP의 수렴 보장 성질

DMP 동역학 (수식 2)에서:

τÿ = αy(βy(yg - y) - ẏ) + f(s)

  • s(0) = 1에서 시작하여 s → 0으로 단조감소
  • f(s) = h(s)(yg - y₀) · s 이므로 s → 0이면 f(s) → 0
  • f(s) = 0이 되면 남는 건 αyβy(yg - y) - αyẏ → 임계감쇠 스프링
  • 이 스프링이 y를 반드시 yg로 끌고 감 (수렴 보장)

즉, yg를 어디로 설정하든 DMP는 반드시 그곳에 도달한다.

학습 과정에서의 처리

Step 1: 원래 궤적 (시작: po⁽ⁱ⁾, 실제 끝: yg⁽ⁱ⁾,actual)에서 h(s) 추출 → 스케일에 무관한 순수 형상 정보만 담김

Step 2: 같은 h⁽ⁱ⁾(s)를 사용하되 목표점만 pg로 바꿔서 DMP를 돌리면:

f_new(s) = h⁽ⁱ⁾(s) · (pg - po⁽ⁱ⁾) · s (여기서 pg - po⁽ⁱ⁾ ≈ pr)

→ Fig. 3(b)가 바로 이 결과 (목표점을 pg로 정합한 수정 궤적)

Step 3: 모든 궤적이 (yg - y₀) ≈ pr이므로 MLP가 일관되게 학습

pr 통일이 중요한 이유

원래:    궤적A: (yg-y₀) = 3m    →  h_A(s) = f / (3·s)
         궤적B: (yg-y₀) = 7m    →  h_B(s) = f / (7·s)

정합 후: 궤적A: (pg-y₀) ≈ 5m   →  f_new = h_A · 5 · s  (3m→5m 으로 늘림)
         궤적B: (pg-y₀) ≈ 5m   →  f_new = h_B · 5 · s  (7m→5m 으로 줄임)

pr이 통일되지 않으면 스케일링 비율이 너무 달라 h(s)의 형상이 과도하게 왜곡된다. pr을 통일하면 MLP 입장에서 h(s)의 변동이 오직 지형 조건 T에만 기인 → 학습이 깔끔해진다.

결론: DMP는 목표점을 어디로 설정하든 수학적으로 반드시 도달하므로, 실제 끝점이 pg와 달라도 문제없다. 수식 (9)의 역할은 도달 가능성이 아니라, 스케일링 비율을 균일하게 맞춰서 학습 품질을 높이는 것이다.

Q35. Fig. 10 평지 굴착에서 시작과 끝의 y값이 다른 이유 — 경사 아닌가?

"평지"는 지형(terrain)이 수평이라는 뜻이지, 궤적의 시작점과 끝점의 y값이 같다는 뜻이 아니다.

궤적 ≠ 지면

버킷 팁의 궤적 (pₓ, py)는 공중에서 시작하여 땅을 파고, 다시 퍼올리는 경로이다:

시작점 (y높음)
   ↘
     ↘ 지면 진입
       ──→──→ 토양 속 굴착 (지면 아래)
              ↗
            ↗ 퍼올림
         끝점 (y는 시작보다 낮을 수 있음)

시작점은 붐을 올린 상태에서 버킷이 진입하는 위치이고, 끝점은 흙을 퍼서 빠져나온 위치이므로 같은 높이일 이유가 없다.

연속 굴착 → 점진적 심화

Fig. 10은 3회 연속 궤적이다:

── 원래 평지 지면 ──────────────

1차 굴착: 살짝 파냄
  ── 1차 후 지면 ──────────

2차 굴착: 더 깊이 파냄
    ── 2차 후 지면 ────

3차 굴착: 가장 깊이 파냄
      ── 3차 후 지면
  • 1차에서 흙을 퍼내면 그 자리의 지면이 낮아짐
  • LiDAR가 변화된 지형을 다시 스캔 → 깊이 파라미터 d가 업데이트
  • Task parameter T = (θ_slope, d)에서 θ_slope = 0 (평지)이지만 d가 점점 커짐
  • DMP가 이에 맞춰 더 깊은 궤적을 자동 생성
평지 경사면
θ_slope 0도 20~32도
연속 굴착 시 변화 깊이 d만 증가 d 증가 + 경사 반영
궤적 시작/끝 y값 차이 있음 (굴착 경로 자체가 곡선) 있음 (더 크게)

Fig. 10에서 y값이 달라 보이는 것은 버킷이 공간에서 움직이는 경로 자체가 곡선이고, 연속 굴착으로 점점 깊어지기 때문이지, 지형이 경사져서가 아니다.

Q36. 식 (8)의 경사면 피팅에서 헤비사이드 함수는 왜 등장하는가?

전체 흐름

LiDAR PCD에서 지형의 기하학적 특징을 추출하는 과정은 다음과 같다:

LiDAR PCD → ROI 추출(x: 3~11m, z: -1.5~1.5m) → z방향 평탄화 → 경사면 피팅(식 8) → 깊이 피팅(가우시안) → Task Parameters T

헤비사이드 함수의 정의

$$H(w) := \frac{d}{dw}\max(w, 0)$$

$\max(w, 0)$은 램프 함수(꺾인 직선)이고, 그 미분이 헤비사이드(계단 함수)이다:

$$H(w) = \begin{cases} 0 & w < 0 \ 1 & w > 0 \end{cases}$$

등장 이유: "구간별 ON/OFF 스위치"

지형이 평탄 → 경사 → 평탄 구간별로 다른 형태를 갖는데, 이것을 하나의 수식으로 표현하려면 if-else 분기 대신 수학적 스위치가 필요하다. 그 역할을 하는 것이 헤비사이드 함수이다.

$H(\cdot)$ 역할
$H(x_1 - x)$ $x < x_1$ 일 때만 1 → 경사 시작 전 구간 활성화
$H(x - x_2)$ $x > x_2$ 일 때만 1 → 경사 끝난 후 구간 활성화

식 (8) 구간별 분석

$$y(x) = ax + b - aH(x_1 - x)(x - x_1) - aH(x - x_2)(x_2 - x) \tag{8}$$

구간 1: $x < x_1$ (경사 시작 전) - $H(x_1 - x) = 1$ (ON), $H(x - x_2) = 0$ (OFF) - $y = ax + b - a(x - x_1) = b + ax_1$ → 상수 (평탄)

구간 2: $x_1 \leq x \leq x_2$ (경사 구간) - 두 $H$ 항 모두 0 (OFF) - $y = ax + b$ → 기울기 $a$의 직선 (경사면)

구간 3: $x > x_2$ (경사 끝난 후) - $H(x_1 - x) = 0$ (OFF), $H(x - x_2) = 1$ (ON) - $y = ax + b - a(x_2 - x) = 2ax + b - ax_2$

참고: 구간 3의 결과가 "평탄"이 아닌 기울기 $2a$가 나온다. 이는 원논문의 수식 이미지가 MD 변환 시 누락되어 요약 복원 과정에서 부호 오류 가능성이 있다. 마지막 항이 $+$ 부호이면 $y = b + ax_2$ (평탄)이 되어 평탄→경사→평탄 모델이 완성된다. 어느 쪽이든 핵심 개념은 동일하다:

  y
  │  ─────────┐
  │            ╲  기울기 a
  │             ╲
  │              └─────────
  └──────────────────────── x
        x₁     x₂

헤비사이드 = 구간 스위치로, 경사 구간 밖에서 기울기를 상쇄하는 보정항을 제어한다.

깊이(pit) 피팅 — 가우시안

경사면 위에 파인 웅덩이의 깊이를 별도로 피팅한다:

$$\text{depth}(x) = d \cdot \exp\left(-\frac{(x - x_o)^2}{c}\right)$$

파라미터 의미
$d$ 웅덩이 최대 깊이
$x_o$ 최심점의 x 좌표
$c$ 웅덩이 폭 스케일

최종 Task Parameters

$$T = (\theta_{\text{slope}}, d) = (\tan^{-1}(a), d)$$

경사면 피팅에서 $a$를 추출하여 경사각 $\theta_{\text{slope}}$, 가우시안 피팅에서 깊이 $d$를 추출하여, 이 두 파라미터가 MLP의 입력으로 들어간다.

Q37. 가우시안 피팅에서 pit은 하나만 존재한다고 가정하는가?

그렇다. 가우시안 함수 하나로 피팅하므로 pit(웅덩이)은 하나만 존재한다고 가정한다.

$$d \cdot \exp\left(-\frac{(x - x_o)^2}{c}\right)$$

이 함수는 봉우리(peak)가 하나인 종 모양이므로, 본질적으로 "가장 깊은 곳이 하나인 단일 웅덩이"만 표현할 수 있다.

이런 단순화가 가능한 이유:

  1. 건설 현장의 일반적 지형: 논문에서 "the most common in construction sites"라고 명시한 대로, 경사면에 웅덩이 하나가 파인 형태가 가장 흔함
  2. 연속 굴착 방식: 같은 위치에서 3회 연속 파내는 방식 → 이전 굴착이 만든 웅덩이가 곧 다음 굴착의 지형이 되므로, 자연스럽게 단일 pit 형태
  3. Task Parameter의 목적: 정밀한 지형 복원이 아니라, DMP 궤적 계획에 필요한 경사각 $\theta_{\text{slope}}$와 깊이 $d$ 두 개만 뽑으면 되므로 충분

만약 pit이 여러 개라면 가우시안 혼합(Gaussian Mixture) 등이 필요하겠지만, task parameter 차원이 늘어나 18세트 소량 데이터로는 학습이 어려워진다.

Q38. Pit의 깊이 $d$는 경사면 수직 방향인가, 수평면 기준인가?

수평면 기준(y방향)이다. 경사면에 수직이 아니다.

근거:

  1. 좌표계: z방향 평탄화 후 (x, y) 평면에서 모든 피팅이 수행됨. 여기서 y는 수직 방향
  2. 가우시안 함수의 구조: 입력이 $x$(수평 위치)이고, 출력이 $y$ 방향의 깊이값 → 수직 방향 깊이
  3. 피팅 순서: 식 (8)로 경사면 피팅 → 잔차(실제 지형 − 경사면)를 가우시안으로 피팅 → 잔차도 y방향으로 측정되므로, $d$는 경사면으로부터 수직 아래(y방향)로 얼마나 파였는가를 나타냄
  y
  │          ╲  경사면 (식 8)
  │           ╲....
  │            ╲   ╲ ← d (수직 방향 깊이)
  │             ╲...╱
  │              ╲
  └──────────────────────── x
                x_o

이것도 단순화의 일종인데, 경사각이 크지 않은 범위(실험에서 20~32도)에서는 수직 깊이와 경사 수직 깊이의 차이가 $\cos\theta$ 배 정도이므로 task parameter로 쓰기에 충분한 근사이다.

Q39. Fig. 8 사다리꼴 패턴의 의미 — 유사 지형에서 전문가의 힘 관리 전략은 일관되는가?

핵심 해석은 맞지만, 한 가지 구분이 필요하다. Fig. 8의 사다리꼴은 DMP의 shaping force $f(s)$가 아니라, 굴착 중 발생하는 외력(contact force) 패턴 $F_{xcv}$이다.

역할 구분 무엇 어디에 사용
shaping force $h(s)$ 전문가의 궤적 형상 학습 Section III — 공칭 궤적 생성
외력 패턴 $F_{xcv}$ 전문가의 힘 관리 전략 학습 Section IV — 온라인 변조 임계값

같은 유형의 지형에서, 굴착 범위나 깊이가 다르더라도, 전문가가 힘을 관리하는 정규화된 패턴은 사다리꼴로 수렴한다. 구체적으로: - 전문가는 힘이 일정 임계값에 도달하면 더 이상 올리지 않고 유지함 - 토양이 단단하든 부드럽든, 깊이가 깊든 얕든, 정규화된 힘의 시간적 프로파일은 유사 - 즉 사다리꼴 = "힘을 과도하게 키우지 않는다"는 전문가의 안전 전략을 수학적으로 포착한 것

이 관찰이 Section IV 온라인 변조 알고리즘의 근거가 된다:

전문가의 관찰 알고리즘 설계
힘이 임계값에서 일정하게 유지됨 $F_{\text{threshold}}$ 설정
임계값 초과 시 궤적을 얕게 수정 $C(s) = \max(F_{xcv} - F_{\text{threshold}}, 0)$, 양의 피드백만 사용

분산(σ)이 말해주는 것:

지형 평균 $E(F_{xcv})$ 표준편차 $\sigma$ 해석
평지 1.62 0.24 패턴이 매우 일관적 — 평지는 예측 가능
경사면 0.86 0.43 분산이 큼 — 경사면은 토양 조건 변동이 크다

경사면에서 분산이 큰 것은 토질·밀도 차이가 크기 때문이지만, 사다리꼴이라는 질적 형태 자체는 유지된다. 토양 재질이 달라도 대표적 힘 관리 형태가 된다는 것이다.

Q40. 힘 임계값 $F_{\text{threshold}}$는 어떻게 정의하였으며, 왜 경사면과 평지에서 다른가?

임계값 설정 방법

논문에서 명시한 것:

"We set the threshold of the excavation force as $F_{th,slope}$ = 1.0 × 10⁵ N and $F_{th,flat}$ = 1.5 × 10⁵ N from experts force data."

별도의 수식이나 알고리즘이 아니라 전문가 힘 데이터의 사다리꼴 plateau 레벨을 관찰하여 직접 설정한 것이다.

왜 경사면의 임계값이 더 낮은가

Fig. 8의 전문가 데이터가 직접적인 근거이다:

지형 전문가 평균 $E(F_{xcv})$ 임계값 $F_{th}$
평지 1.62 (높음) 1.5 × 10⁵ N (높음)
경사면 0.86 (낮음) 1.0 × 10⁵ N (낮음)

전문가 스스로가 경사면에서 더 작은 힘을 유지한다. 그 이유는:

  1. 전복(overturning) 위험: 경사면에서는 굴삭기의 무게중심이 이미 기울어져 있으므로, 같은 크기의 굴착 반력에도 전복 모멘트가 훨씬 크게 작용
  2. 반력 방향의 차이: 평지에서는 반력이 주로 수평 방향(접지 마찰로 버팀), 경사면에서는 경사 방향 성분이 추가되어 굴삭기를 밀거나 들어올리는 힘으로 작용
  3. 전문가의 경험적 판단: 논문에서 전문가 인터뷰를 언급 — "experts can recognize the external force on the bucket through the excavator movement in response to the joystick manipulation, and they modify the path in real-time if excessive force occurs"

한계점

이 임계값 설정은 논문의 약점 중 하나이다:

  • 전문가 데이터에서 수동으로 읽어낸 값 (자동화 아님)
  • 지형 유형별로 별도 임계값을 미리 설정해야 함
  • 연속적인 경사각 변화에 대한 임계값 보간/일반화 방법이 없음
  • 논문의 "향후 연구"에서도 최적 coupling gain 탐색을 미해결 과제로 남겨둠

이상적으로는 $F_{th}(\theta_{\text{slope}})$ 같은 경사각의 연속 함수로 모델링하거나, 전복 안정성 해석에서 역산하는 것이 더 체계적이겠지만, 18세트 소량 데이터에서 실기 검증에 초점을 맞춘 논문이므로 단순한 방법을 택한 것으로 보인다.
