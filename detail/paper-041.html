TaskNet: 자율굴착기 신경망 작업계획기

TaskNet: A Neural Task Planner for Autonomous Excavator

Jinxin Zhao, Liangjun Zhang

Obsidian 최신 요약·근거 노트
  • Baidu 자율굴착 논문 카드 요약 2019-2024
  • Baidu 자율굴착 논문 핵심 분석 2019-2024
한줄 요약 — TaskNet은 목표 지형과 현재 LiDAR 높이맵의 차를 계층적 격자로 표현하고, 서로 다른 가중치를 가진 두 CNN 기반 계획기 TEM과 CEM이 상위 move/excavate 하위작업부터 approach/dig primitive의 위치·깊이·종료까지 순차 분해해 기존 경로·궤적계획기로 넘기는 데이터 기반 굴착 작업계획기다.

1.연구 배경 및 동기

규칙 기반 굴착 작업분해를 시연학습 가능한 계층 계획기로 전환

자율굴착은 한 번의 버킷 궤적뿐 아니라 차체를 어느 위치로 옮길지, 각 위치에서 어느 영역을 얼마나 깊게 굴착할지, 언제 다음 영역으로 넘어갈지를 긴 시퀀스로 정해야 한다. 이산 작업결정과 연속 충돌회피 운동을 동시에 탐색하면 공간이 커지고, 장비 도달범위를 지키면서 베이스 이동을 줄이는 전략까지 수작업으로 설계해야 한다.

기존 FSM·스크립트는 작업과 지형이 바뀔 때 규칙을 다시 작성해야 한다. TaskNet은 목표와 현재 LiDAR 높이의 차를 도달영역 단위 tile map과 버킷 폭 단위 cell map으로 나눈다. TEM은 move_to_tile/excavate_tile을, CEM은 approach/dig와 위치·깊이·종료를 예측한다. 출력은 기존 차체 경로·팔 궤적계획기로 전달되어 학습기는 계층적 작업분해에 집중한다.

선행 연구의 한계
  • FSM·스크립트는 새 지형·작업마다 상태와 전이 규칙을 다시 설계해야 한다.
  • 작업과 운동의 결합 탐색은 이산 sub-task와 연속 궤적 때문에 고차원이다.
  • 순수 imitation learning은 재귀 계획의 종료판단을 안정적으로 배우기 어렵다.
  • TEM과 CEM은 베이스 이동 최소화와 국소 최대 굴착이라는 서로 다른 전략을 요구한다.
이 연구의 기여
  • 굴착 목표를 sub-task·사양과 실행 가능한 primitive·사양으로 재귀 분해하는 신경 계획기를 제안했다.
  • 도달영역 TEM과 버킷-cell CEM을 같은 구조·다른 가중치로 설계했다.
  • 대규모 합성 trace와 인간 운전 fine-tuning을 결합해 3.5톤 simulation과 49톤 실차에서 검증했다.

2.방법론 및 시스템 구성

현재 높이 G와 목표 G_target의 차이가 모든 셀에서 epsilon 이내면 완료다. 원 격자를 굴착기 한 정차점의 도달영역 크기로 downsample해 binary G_tile을 만들고, 선택 tile에서는 버킷 폭 해상도의 G_cell을 자른다. 이 계층은 상위 이동과 하위 굴착이 필요한 공간 해상도를 분리한다.

TEM은 tile map과 최근 sub-task 이력으로 move_to_tile/excavate_tile, 방향·지역 사양과 전체 종료를 출력한다. 이동이면 PATH가 move_base 경로를 만들고, 굴착이면 CEM이 local cell map과 직전 approach에서 approach/dig, 좌표·깊이, 지역 종료를 예측한다. 두 모델은 CNN 2층과 출력별 FC decoder를 갖고 세 cross-entropy의 가중합으로 학습하되 core 가중치는 공유하지 않는다.

1

LiDAR 현재 높이와 목표 높이의 차를 만들고 모든 셀이 epsilon 이내인지 검사한다.

2

2. 계층 격자

도달영역 크기의 G_tile과 버킷 폭 크기의 G_cell로 상·하위 입력을 분리한다.

3

3. TEM 예측

tile map과 이동 이력에서 move/excavate, 사양, 전체 종료를 출력한다.

4

4. PATH 이동

이동방향을 세계좌표로 바꾸고 grid search로 move_base 경로를 만든다.

5

5. CEM 예측

local map과 직전 approach에서 approach/dig, 좌표·깊이, 지역 종료를 출력한다.

6

6. 운동계획

primitive 사양을 팔 trajectory optimization과 차체 경로계획기에 전달한다.

7

7. 관측 갱신

실행 후 cell·tile map을 갱신해 전체 작업 완료까지 재귀 반복한다.

8

8. 합성학습

TEM 순회·건너뛰기와 CEM 최고 cell 우선 규칙으로 대규모 trace를 만든다.

9. 실차 적응

인간 운전 trace로 49톤 굴착기 시험 전 모델을 fine-tune한다.

원문 수식과 의미

목표 지형 완료조건 (Eq. 1)

|G(p,q)-G_{target}(p,q)|<\epsilon,\ \forall p,q

PDF p.2. 모든 셀의 현재-목표 높이차가 허용오차 안이면 완료다.

TEM 상위계획 (Eq. 2)

(s^{(t)},a^{(t)},t_e)=\Psi_{TEM}(t_a,o^{(t)})

PDF p.3. 작업과 tile 관측에서 sub-task·사양·전체 종료를 낸다.

CEM 하위계획 (Eq. 3)

(p^{(i)},b^{(i)},\tilde t_e)=\Psi_{CEM}(a^{(i)},\tilde o^{(i)})

PDF p.3. 지역 관측에서 primitive·사양·지역 종료를 낸다.

PATH 이동계획 (Eq. 4)

(p^{(i)},b^{(i)},\tilde t_e)=\Psi_{PATH}(a^{(i)},\tilde o^{(i)})

PDF p.3. move_to_tile 사양을 move_base 경로로 바꾼다.

공통 다중 decoder 구조 (Eq. 5)

x=f_{core}(u),\ y_1=f_x(x),\ y_2=f_{spec}(x),\ y_3=f_{term}(x)

PDF p.3. core 특징을 행동·사양·종료 decoder가 각각 해석한다.

TEM 입력 (Eq. 6)

u^{(t)}=(G_{tile}^{(t)},(s^{(t)},s^{(t-1)},\ldots,s^{(t-k)}))

PDF p.4. tile map과 최근 처리 이력을 함께 사용한다.

CEM 입력 (Eq. 7)

u^{(i)}=(G_{cell}^{(i)},b^{(i-1)})\in\mathbb{R}^{h\times w\times2}

PDF p.4. local map과 직전 approach를 두 채널로 결합한다.

지도학습 손실 (Eq. 8)

L=\sum \alpha L_p(y_1,\hat y_1)+\beta L_b(y_2,\hat y_2)+\gamma L_t(y_3,\hat y_3)

PDF p.4. 행동·사양·종료 cross-entropy의 가중합이다.

3.핵심 기술

TEM-CEM 이중 시간척도

TEM은 넓은 현장을 정차·도달영역 단위로, CEM은 한 정차점의 버킷 cell·깊이 단위로 계획한다. 베이스 이동 최소화와 국소 최대 굴착의 전략이 달라 core 가중치를 공유하지 않으며, 공유-core baseline의 tile sub-task 실패가 이를 뒷받침한다.

  • TEM: move/excavate
  • CEM: approach/dig
  • PATH: move_base
  • 상·하위 종료 별도 예측

높이차 격자와 사양 전달

TaskNet은 현재-목표 높이차를 공통 표현으로 쓴다. tile은 처리 여부를 압축하고 cell은 버킷 굴착 위치를 보존한다. 출력이 class에 그치지 않고 방향·국소좌표·깊이를 포함하므로 기존 모션플래너가 연속 궤적을 계산할 수 있다.

  • tile=도달영역
  • cell=버킷 폭
  • 방향·좌표·깊이 출력
  • 학습계획과 운동계획 분리

합성 시연과 실차 미세조정

TEM은 순회·비작업 tile 건너뛰기, CEM은 최고 cell 우선 규칙으로 대량 trace를 얻는다. 실제 백만 단위 label 수집을 피하지만 합성 규칙이 전략을 선결정할 수 있어, 저자들은 인간 운전 trace로 실차 전 fine-tuning했다.

  • TEM 1,126,900 sample
  • CEM 10,000 sequence
  • 실차 fine-tuning
  • few-shot이 후속과제

4.실험 결과

실험 환경·장비·데이터

  • TEM: 최대 32×32의 3,000개 map, 총 1,126,900 sample.
  • CEM: 최대 6×6의 10,000 sequence, batch 1,000, learning rate 1e-3.
  • 비교군은 naive pure IL과 TEM·CEM core-share 변형이다.
  • 3.5톤 particle-terrain simulator와 LiDAR·IMU 장착 49톤 drive-by-wire 굴착기를 사용했다.

실험 프로토콜

  • 미학습 randomized map에서 필요한 tile의 zig-zag 순회와 비작업 tile 건너뛰기를 확인했다.
  • Table II에서 세 모델의 tile·cell plan 완료 여부와 실패 유형을 비교했다.
  • pile·trench·multiple-block 작업을 지형 갱신이 포함된 simulation 폐루프로 실행했다.
  • 실차 54회에서 추론·primitive 시간과 총 운반체적/시간을 기록해 인간 효율과 비교했다.

비교 기준

  • Pure IL: cell termination failure.
  • Core-share: tile sub-task failure.
  • 인간 운전자: 동일 실차 작업의 m³/h 비교.

평가 지표

  • tile/cell 완료
  • 학습 규모
  • 추론·실행시간
  • 54회 적재 m³/h
  • 미학습 지형 완료

핵심 결과 해석

TaskNet은 Table II의 tile·cell plan을 모두 완료했다. Pure IL은 cell 종료를 못했고, core-share는 tile sub-task 선택에 실패했다. TEM은 학습에 없던 무작위 30×30 사례에서 필요한 tile을 zig-zag로 덮고 비작업 tile을 건너뛰었다. 3.5톤 simulation의 pile·trench·multiple-block도 폐루프로 수행했지만 성공률이나 목표형상 오차는 수치로 보고하지 않았다.

49톤 실차에서 다음 primitive·사양 추론은 1초 미만, approach는 약 2초, dig·swing·dump 합계는 약 22초였다. 54회 적재의 자율 효율은 356.8 m³/h, 인간은 396.5 m³/h였다. 자율 처리량은 인간의 약 90%이나 TaskNet 단독 효과가 아니라 모션플래너·제어기와 현장조건을 포함한 통합 시스템 성과다.

실패 사례와 경계조건
  • Pure IL은 cell 종료판단 실패로 지역 계획을 끝내지 못했다.
  • Core-share는 tile 수준의 올바른 sub-task 선택에 실패했다.
  • 합성 규칙 밖 지형의 정량 일반화율과 센서오차·안전 실패 빈도는 보고되지 않았다.

5.한계 및 향후 연구

현재 한계

  • 대부분의 trace가 규칙 기반 simulator라 zig-zag·최고 cell 우선 전략을 답습할 수 있다.
  • 실차 fine-tuning 데이터 규모·비율·epoch가 없어 sim-to-real 재현성이 제한된다.
  • 높이 기하만 사용해 soil texture·hardness·저항력·버킷 힘을 반영하지 않는다.
  • 실차는 단일 49톤 장비·적재 시나리오이고 평가도 binary 완료와 처리량 중심이다.

향후 연구

  • 원문은 격자에 soil texture와 hardness를 추가하고 few-shot으로 실데이터 요구량을 줄이는 방향을 제시한다.
  • 버킷 힘·유압압력·실제 충전율을 넣어 다음 깊이와 접근점을 성과 기반으로 보정할 수 있다.
  • 완료율, termination F1, 목표형상 RMSE, 안전개입률과 재계획 지연을 새 현장에서 평가해야 한다.

6.한마디로 정리

핵심 방법은?

높이차를 tile·cell로 나누고 TEM·CEM이 sub-task·primitive·사양·종료를 시연학습해 기존 모션플래너로 넘긴다.

핵심 결과는?

TaskNet만 두 계획시험을 모두 완료했고, 49톤 굴착기 54회에서 356.8 m³/h로 인간 396.5 m³/h에 근접했다.

한계는?

합성 규칙 의존, 물성·힘 정보 부재, 단일 실차 현장과 완료 중심 평가로 OOD 일반화·안전성은 미확인이다.

나의 의견 / 우리 연구와의 연관성

TaskNet은 규칙형 AES의 작업분해를 데이터 기반으로 바꾸면서 검증된 모션플래너를 유지한다. rank 40의 버킷 적재 체적을 CEM 종료와 다음 dig 깊이에 되먹이면 최고 cell 규칙을 실제 충전효율로 교정할 수 있다. 주행성 지도는 위험 tile을 막고, rank 42 안전감시는 장비 침입 때 primitive를 pause한 뒤 관측 갱신·재계획을 유도할 수 있다.

  • 버킷 체적을 CEM termination·depth specification에 되먹여 저충전 굴착을 재계획한다.
  • 토질·유압 힘을 입력 채널로 추가해 재료 조건부 primitive와 에너지 최적화로 확장한다.
  • 주행성 비용을 TEM tile mask와 PATH에 연결해 거친 지형의 베이스 재배치를 안전하게 만든다.
  • 외부 안전감시 경보를 pause·대기·재개 sub-task로 통합한다.
